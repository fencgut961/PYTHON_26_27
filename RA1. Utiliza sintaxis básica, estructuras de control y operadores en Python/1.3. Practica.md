# 🔹 Práctica 1.3. Netflix Smart Profile & Catalog Router

---

## 📖 Contexto del proyecto

Trabajas en el equipo de ingeniería del backend de **Netflix**. El sistema de distribución de *streaming* necesita procesar la información del perfil de un usuario que acaba de iniciar sesión para determinar de forma automatizada y segura:

1. Si el perfil tiene restricciones de acceso por edad.
2. La calidad máxima de reproducción autorizada según su plan de suscripción.
3. La sugerencia personalizada del catálogo destacada en su pantalla de inicio.

Tu tarea consiste en diseñar un script en Python que capture los datos del perfil, aplique normalización de cadenas, evalúe reglas mediante estructuras condicionales y devuelva un informe formateado.

---

## 🎯 El reto

El programa solicitará tres datos de entrada a través de la consola mediante `input()`:

* **Edad** del usuario (número entero).
* **Plan de suscripción** (cadena de texto introducida por el usuario con posibles inconsistencias de formato).
* **Género favorito** de entretenimiento (ej. `Acción`, `Comedia`, `Sci-Fi`, `Anime`).

El script procesará las reglas de negocio utilizando **`if...elif...else`** para las validaciones dinámicas y **`match-case`** para el enrutamiento de catálogo.

---

## 🛠️ Requisitos del programa

Crea un script en Python llamado `ra1_act3_netflix_catalog_router.py` que ejecute secuencialmente los siguientes bloques:

### Paso 1: Normalización y saneamiento de datos

Para garantizar comparaciones insensibles a mayúsculas, minúsculas o espacios accidentales:

* **Plan de suscripción:** Elimina espacios extremos mediante `.strip()` y convierte todo el texto a minúsculas con `.lower()` *(ej. `"  pReMiUm  "` $\rightarrow$ `"premium"`)*.
* **Género favorito:** Elimina espacios extremos y aplica formato de primera letra mayúscula usando `.strip().capitalize()` *(ej. `"  sci-fi  "` $\rightarrow$ `"Sci-fi"` / `"Sci-Fi"`, `"acción"` $\rightarrow$ `"Acción"`)*.

### Paso 2: Control parental y calidad de streaming (`if...elif...else`)

* **Control Parental:** Si el usuario tiene **menos de 16 años** y su género favorito normalizado es **"Acción"**, el estado del control parental pasa a ser **`"RESTRICCIÓN ACTIVA"`**. Se mostrará una advertencia en consola y se modificará automáticamente su género a **"Comedia"** de forma preventiva. En cualquier otro caso, el estado del control parental será **`"ACCESO PERMITIDO"`**.
* **Calidad de Streaming:** Determina la resolución máxima autorizada según el plan de suscripción:

| Plan Normalizado | Calidad Autorizada |
| --- | --- |
| `"premium"` | **"Ultra HD (4K)"** |
| `"estándar"` / `"estandar"` | **"Full HD (1080p)"** |
| `"básico"` / `"basico"` | **"HD (720p)"** |
| *Cualquier otro valor* | **"SD (480p)"** *(Mostrar advertencia de plan no reconocido)* |

### Paso 3: Enrutador de catálogo personalizado (`match-case`)

Usa la sentencia **`match-case`** sobre el género favorito (evaluando la variable tras la posible reasignación del Paso 2) para asignar la recomendación principal:

| Género Evaluado | Serie / Película Sugerida |
| --- | --- |
| `"Sci-fi"` / `"Sci-Fi"` / `"Ciencia ficción"` | **"Stranger Things"** |
| `"Anime"` / `"Manga"` | **"One Piece"** |
| `"Comedia"` / `"Humor"` | **"Wednesday"** *(Miércoles)* |
| `"Acción"` / `"Accion"` | **"Cobra Kai"** |
| `_` *(Comodín por defecto)* | **"La Casa de Papel"** |
