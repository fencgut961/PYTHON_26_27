# 🔹 Práctica 1.5 - Spotify Smart Playlist & Queue Manager

---

## 📖 Contexto del proyecto

En plataformas de *streaming* de música y *podcasts* como **Spotify**, la reproducción secuencial de pistas requiere algoritmos en tiempo real capaces de tomar decisiones dinámicas sobre el flujo de audio.

En esta actividad, diseñarás el motor lógico de un **gestor de cola de reproducción inteligente** capaz de procesar canciones, omitir publicidad (*Ad Skipping*), ignorar archivos de audio corruptos y ejecutar un protocolo de apagado de emergencia si se detecta un evento crítico en el dispositivo.

---

## 🎯 El reto

Dispones de la siguiente cola de reproducción en bruto dentro de tu programa:

```python
cola_reproduccion = [
    "SONG: Blinding Lights - The Weeknd",
    "AD: Coca-Cola Summer Splash",
    "SONG: Starboy - The Weeknd",
    "ERROR: Audio File Corrupt (0x302)",
    "SONG: Die With A Smile - Bruno Mars",
    "AD: Spotify Premium Promo",
    "SONG: One Dance - Drake",
    "CRITICAL: Battery Low 2%",
    "SONG: Stay - Justin Bieber"
]

```

Debes escribir un script en Python que recorra secuencialmente esta cola de datos mediante un bucle `for` y altere el flujo de ejecución mediante las sentencias **`break`** y **`continue`** según la etiqueta de cada elemento.

---

## 🚫 Restricciones del ejercicio (Patrón Anti-IA)

👉 Para garantizar la evaluación objetiva de las estructuras de control aprendidas:

* Está **totalmente prohibido** modificar manualmente la lista `cola_reproduccion` antes de iniciar la iteración.
* Está **totalmente prohibido** crear funciones personalizadas (`def`) o clases de programación orientada a objetos (POO).
* El script debe cumplir estrictamente las normas de estilo **PEP 8**: nombres en `snake_case`, comentarios explicativos y un **Docstring de triple comilla** (`"""`) al inicio del archivo describiendo el propósito del script.

---

## 🛠️ Requisitos del programa

Crea un script en Python denominado `ra1_act5_spotify_queue_manager.py` que cumpla con los siguientes criterios de procesamiento:

1. **Recorrido de la Cola:** Iterar secuencialmente sobre `cola_reproduccion` con un bucle `for`.
2. **Filtro de Anuncios (`AD:`):**
* Si el elemento contiene la etiqueta `"AD:"`, imprime: `"[Saltando Anuncio] -> [Nombre del anuncio]"`.
* Usa **`continue`** para omitir el procesamiento del anuncio sin incrementar el contador de canciones.


3. **Filtro de Errores (`ERROR:`):**
* Si el elemento contiene la etiqueta `"ERROR:"`, imprime: `"[Fallo de Conexión] -> Omitiendo archivo dañado: [Detalle del error]"`.
* Usa **`continue`** para ignorar el archivo corrupto y pasar al siguiente elemento.


4. **Apagado de Emergencia (`CRITICAL:`):**
* Si el elemento contiene la etiqueta `"CRITICAL:"`, imprime: `"[ALERTA DEL SISTEMA] -> [Detalle del aviso]. Apagando reproductor..."`.
* Usa **`break`** para detener inmediatamente la ejecución del bucle.


5. **Reproducción Válida (`SONG:`):**
* Si es una canción válida (`"SONG:"`), imprime: `"🔊 Reproduciendo: [Nombre de la canción]... [OK]"`.
* Incrementa un contador entero con la cantidad de canciones reproducidas con éxito.


6. **Reporte Final:** Imprime un resumen con el total acumulado de canciones escuchadas.
