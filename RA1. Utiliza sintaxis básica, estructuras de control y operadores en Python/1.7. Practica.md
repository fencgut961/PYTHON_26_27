## 📖 Contexto del proyecto

En el equipo de desarrollo backend de una plataforma integradora de servicios de *streaming* (como Netflix y Disney+), se procesan métricas de consumo de ancho de banda y tarificación mensual para cuentas compartidas en hogares.

Un desarrollador junior ha entregado un script inicial para automatizar estos cálculos. Aunque el programa no arroja errores de sintaxis (*SyntaxError*) ni se detiene de forma abrupta, contiene **graves errores lógicos**: la ejecución entra en bucles infinitos, los importes de facturación con IVA devuelven resultados incoherentes y el sistema lanza alertas de red de forma inversa a las reglas de negocio.

Tu función como ingeniero de calidad es utilizar el **depurador (*Debugger*)** de tu IDE para congelar la ejecución con puntos de interrupción (*breakpoints*), inspeccionar la memoria paso a paso, corregir los errores lógicos y documentar las resoluciones aplicadas.

---

## 🎯 El reto

Debes depurar y corregir el archivo `ra1_act7_streaming_debugger.py` identificando y solucionando tres fallos críticos de lógica:

1. **Un bucle `while` infinito** en el registro de perfiles de usuario.
2. **Un error de precedencia y cálculo numérico** al aplicar el porcentaje de IVA ($21\%$) sobre el subtotal de suscripción.
3. **Un error en la evaluación booleana** de la alerta de congestión de red según el tipo de conexión (Fibra vs. ADSL).

## 🛠️ Código inicial a corregir (Plantilla con errores)

Crea el archivo `ra1_act7_streaming_debugger.py` e introduce la siguiente plantilla defectuosa:

```python
"""
Plantilla Inicial - Simulador de Cuentas de Streaming (CON ERRORES LÓGICOS)
Propósito: Calcular consumo de red y tarifas de suscripción familiar.
"""

print("--- REPORTE DE INICIO DE SESIÓN DE STREAMING ---")

# --- VARIABLES DE CONFIGURACIÓN ---
PLAN_BASE_NETFLIX = 9.99
PLAN_BASE_DISNEY = 5.99
COSTO_EXTRA_PERFIL_4K = 2.50
DESCUENTO_COMBO = 3.00       # Descuento por contratar ambas plataformas
IMPUESTO_IVA = 0.21         # 21% de IVA aplicable al total final

# --- REGISTRO DE PERFILES ACTIVOS (Bucle de Control) ---
perfiles_registrados = 0
maximo_perfiles = 3

while perfiles_registrados < maximo_perfiles:
    nombre_perfil = input(f"Introduce nombre para perfil #{perfiles_registrados + 1}: ")
    nombre_limpio = nombre_perfil.strip()
    print(f"-> Perfil '{nombre_limpio}' registrado con éxito.")
    # NOTA DE DEPURACIÓN: El contador 'perfiles_registrados' no se incrementa.

# --- SELECCIÓN DE CALIDAD DE STREAMING ---
print("\n--- CONFIGURACIÓN DE RESOLUCIÓN ---")
perfiles_en_4k = int(input("¿Cuántos perfiles usarán transmisión en 4K?: "))

# --- CÁLCULO DE COSTES ---
# Fórmula deseada: Subtotal = Netflix + Disney - Descuento + (Perfiles 4K * Costo Extra)
subtotal_suscripcion = (
    PLAN_BASE_NETFLIX + PLAN_BASE_DISNEY - DESCUENTO_COMBO + (perfiles_en_4k * COSTO_EXTRA_PERFIL_4K)
)

# ERROR LÓGICO: Operación de IVA errónea
total_con_iva = subtotal_suscripcion * 1.0 + IMPUESTO_IVA

print(f"\nSubtotal calculado: {subtotal_suscripcion:.2f}€")
print(f"Total Neto con IVA: {total_con_iva:.2f}€")

# --- ESTIMACIÓN DE ANCHO DE BANDA ---
# Regla de negocio: Perfil HD = 5.0 Mbps | Perfil 4K = 15.0 Mbps.
# Si el consumo total supera 20 Mbps y la red NO es de Fibra, emitir advertencia.

perfiles_hd = maximo_perfiles - perfiles_en_4k
consumo_total_mbps = (perfiles_hd * 5.0) + (perfiles_en_4k * 15.0)

tipo_red = input("\n¿Tipo de conexión ('Fibra' o 'ADSL')?: ").strip().capitalize()
es_fibra = tipo_red == "Fibra"

print(f"\nConsumo estimado de red: {consumo_total_mbps:.1f} Mbps")

# ERROR LÓGICO: Evaluación condicional invertida
if consumo_total_mbps > 20.0 and es_fibra == True:
    print("⚠️ ADVERTENCIA: Alto consumo detectado. Riesgo de microcortes.")
else:
    print("✅ Estado de conexión: Red estable para streaming simultáneo.")

```

## 🕵️‍♂️ Flujo de depuración guiado

Aplica el siguiente procedimiento sistemático dentro de tu IDE (IntelliJ IDEA / PyCharm):

### Paso 1: Diagnóstico del bucle infinito

1. Coloca un **breakpoint** en la línea `while perfiles_registrados < maximo_perfiles:`.
2. Ejecuta el script en modo **Debug** (`Shift + F9` o icono del escarabajo 🪲).
3. Introduce el nombre de un perfil en la consola interactiva.
4. Presiona **Step Over (`F8`)** para avanzar línea por línea y observa el panel de variables: `perfiles_registrados` permanece estancado en `0`.
5. **Solución:** Agrega la instrucción `perfiles_registrados += 1` en el cuerpo del bucle.

### Paso 2: Depuración del cálculo del IVA

1. Sitúa un **breakpoint** en la declaración de `total_con_iva`.
2. Inspecciona el valor de `subtotal_suscripcion` en el panel de variables.
3. Evalúa la expresión actual: $\text{subtotal} \times 1.0 + 0.21$ suma únicamente 21 céntimos al subtotal.
4. **Solución:** Reestructura la ecuación para aplicar el factor multiplicador correspondiente:

$$\text{total\_con\_iva} = \text{subtotal\_suscripcion} \times (1 + \text{IMPUESTO\_IVA})$$



### Paso 3: Corrección de la alerta de red

1. Sitúa un **breakpoint** en la sentencia condicional `if consumo_total_mbps > 20.0...`.
2. Prueba el escenario ingresando conexión `"ADSL"` (`es_fibra = False`) y $3$ perfiles en $4\text{K}$ ($45.0\text{ Mbps}$).
3. Al evaluar `es_fibra == True`, la condición completa resulta `False` y salta erróneamente al bloque `else`.
4. **Solución:** Ajusta la cláusula para evaluar la ausencia de fibra mediante `not es_fibra` o `es_fibra == False`.
