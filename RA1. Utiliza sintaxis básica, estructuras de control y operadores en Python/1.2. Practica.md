# 🔹 Práctica 1.2. Twitch Custom Stream Alerts & Rewards Router

---

## 📖 Contexto del proyecto

En las plataformas de *streaming* actuales como Twitch o YouTube Gaming, los bots de chat y los *overlays* de pantalla procesan constantemente tramas de datos recibidas del servidor para activar alertas en vivo y asignar permisos especiales (chats exclusivos, recompensas o *emotes* personalizados).

En esta actividad, diseñarás el motor de evaluación lógica para un bot de Twitch que analiza el perfil de un espectador y calcula automáticamente sus recompensas, accesos VIP y alertas del canal.

---

## 🎯 El reto

El programa debe simular la recepción de una trama de red compacta enviada por la plataforma:

```python
trama = "VIEWER-7890_TIER-2_BITS0250_WATCH045_MOD1"

```

El script recortará la trama, procesará sus valores de forma secuencial y ejecutará un análisis de acceso y recompensas mediante **expresiones lógicas compuestas**.

---

## 🚫 Restricciones del ejercicio (Patrón Anti-IA)

👉 Para afianzar el uso de lógica booleana pura:

* Está **totalmente prohibido** usar sentencias condicionales (`if`, `elif`, `else`).
* Está **totalmente prohibido** usar bucles (`for`, `while`).
* Todo el enrutamiento lógico debe resolverse evaluando condiciones relacionales y asignando el resultado directamente a variables booleanas (`True` o `False`).

---

## 🛠️ Requisitos de la actividad

### 1. Extracción y Limpieza de Datos (Slicing)

A partir de la variable `trama`, utiliza rebanados de cadena (`slicing`) para extraer cada parámetro:

| Rango de Índices | Campo Extraído | Procesamiento y Casting |
| --- | --- | --- |
| `0:11` | **ID Espectador** | Conservar como `str` (ej. `"VIEWER-7890"`). |
| `12:18` | **Nivel Suscripción** | Conservar como `str` (ej. `"TIER-2"`). |
| `19:27` | **Bits Enviados** | Omitir el prefijo `"BITS"` (slicing interno) y convertir a `int` (ej. `250`). |
| `28:36` | **Horas Vistas** | Omitir el prefijo `"WATCH"` (slicing interno) y convertir a `int` (ej. `45`). |
| `37:41` | **Rol Moderador** | Extraer el código y convertir a `bool` (`True` si equivale a `"MOD1"`, `False` si es `"MOD0"`). |

🔍 **Pista de casting booleano:** Puedes convertir directamente la comparación en un estado booleano mediante igualdad de cadenas (`es_moderador = subcadena == "MOD1"`).

### 2. Motor de Reglas Lógicas (Sin `if`)

Define las siguientes variables booleanas combinando operadores relacionales (`==`, `!=`, `>`, `<`, `>=`, `<=`) y lógicos (`and`, `or`, `not`):

1. **`es_suscriptor_activo`:** Será verdadero si el nivel de suscripción es distinto de `"TIER-0"`.
2. **`es_donador_destacado`:** Será verdadero si los bits enviados son estrictamente mayores a `200`.
3. **`tiene_recompensa_fidelidad`:** Verdadero si ha acumulado más de `40` horas de visualización **y además** es un suscriptor activo.
4. **`activar_alerta_shoutout`:** Se dispara si el espectador es Moderador **o** si es un donador destacado.
5. **`tiene_acceso_chat_vip`:** Se concede a los moderadores de forma automática, **o bien** a cualquier espectador que sea suscriptor activo con más de `10` horas vistas.
