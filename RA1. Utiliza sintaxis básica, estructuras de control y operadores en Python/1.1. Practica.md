# 🔹 Práctica 1.1: Video Game Character Parser

---

## 📖 Contexto del proyecto

En el desarrollo de videojuegos de rol (RPG) y arquitectura cliente-servidor, los datos de red suelen enviarse de forma compacta en tramas de ancho fijo para optimizar el ancho de banda.

Tu tarea consiste en diseñar un script en Python que reciba una trama de datos crudos, extraiga la información del héroe utilizando técnicas de **slicing** (rebanado de cadenas) y realice los cálculos de combate necesarios sin recurrir a estructuras condicionales (`if`) ni bucles (`for`/`while`).

---

## 🎯 El reto

Debes procesar la siguiente trama de red que representa el estado actual de un personaje:

```python
trama_red = "ARAGORN    -0850-1.20-1"

```

La trama mide exactamente **22 caracteres** y se desglosa con la siguiente estructura:

| Rango de Índices | Campo | Tipo Esperado | Descripción |
| --- | --- | --- | --- |
| `0:10` | **Nombre** | `str` | Ancho fijo de 10 caracteres (relleno con espacios). |
| `10` | **Separador** | `-` | Guion de separación. |
| `11:15` | **Ataque Base** | `int` | Número entero representado con 4 dígitos. |
| `15` | **Separador** | `-` | Guion de separación. |
| `16:20` | **Multiplicador Crítico** | `float` | Número decimal en formato `X.XX`. |
| `20` | **Separador** | `-` | Guion de separación. |
| `21` | **Potenciador Activo** | `bool` | Indicador binario (`"1"` = activo, `"0"` = inactivo). |

---

## 🛠️ Requisitos del programa

Escribe un script en Python llamado `ra1_act1_video_game_character_parser.py` que ejecute los siguientes pasos:

1. **Definir la trama:** Declara la variable `trama_red` con la cadena exacta indicada arriba.
2. **Aplicar Slicing:** Extrae de forma manual cada uno de los cuatro campos (nombre, ataque, crítico y potenciador) utilizando los rangos de índices exactos.
3. **Limpieza de textos:** Aplica el método `.strip()` sobre el nombre extraído para eliminar los espacios en blanco sobrantes a los lados.
4. **Conversión de tipos (Casting):**
* Convierte la subcadena de ataque base a entero (`int`).
* Convierte la subcadena de multiplicador crítico a decimal (`float`).
* Convierte el carácter del potenciador activo a booleano (`bool`).


🔍 **Pista de seguridad para el casting booleano:**
Si ejecutas `bool("0")`, obtendrás `True` porque `"0"` es una cadena no vacía. Para convertir correctamente el carácter `"1"` o `"0"` a su booleano real, convierte primero la subcadena a entero (`int`) y posteriormente a booleano (`bool(int(subcadena))`).
5. **Cálculo del daño de combate:**
* Calcula el **Daño Crítico Máximo** multiplicando el ataque base por el multiplicador crítico.


6. **Mostrar Reporte:** Imprime en consola la información procesada utilizando **f-strings** con el siguiente formato de tabla:

```text
========================================
        REPORTE DE PERSONAJE RPG        
========================================
Nombre del Héroe:   [Nombre limpio]
Ataque Base:        [Ataque] pts
Multiplicador Crí:  [Crítico]x
Potenciador Activ:  [True / False]
----------------------------------------
DAÑO CRÍTICO MAX:   [Daño calculado] pts
========================================

```
