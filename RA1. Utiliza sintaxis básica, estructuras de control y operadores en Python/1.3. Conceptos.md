## 📚 La Indentación como Estructura de Control

A diferencia de lenguajes con sintaxis basada en llaves `{ }` como Java, C++ o C#, **Python utiliza la indentación física (espacios en blanco) obligatoria** para delimitar los bloques de código.

* **Regla de los 4 espacios:** Cada bloque condicional debe estar desplazado exactamente **4 espacios a la derecha** respecto a la línea de cabecera.
* **Operador de apertura de bloque:** La cabecera de la estructura condicional siempre finaliza con el carácter de dos puntos (`:`).
* **Consistencia:** Si se combinan espacios con tabuladores o no se respeta la sangría, el intérprete lanzará un error de sintaxis (`IndentationError`) o generará fallos lógicos no detectados en compilación.

```python
# Ejemplo correcto ✅
edad = 18
if edad >= 18:
    print("Acceso permitido")
    print("Bienvenido al sistema")  # Ambos prints pertenecen al mismo bloque condicional

# Ejemplo incorrecto ❌
if edad >= 18:
print("Acceso permitido")  # Error de sintaxis (IndentationError)

```

## ⚙️ Bifurcaciones Condicionales: `if...elif...else`

La estructura condicional evalúa expresiones booleanas o expresiones evaluables como *Truthy* / *Falsy*.

### 1. Estructura Simple (`if`)

Ejecuta el bloque de código únicamente si la condición resulta ser `True`.

```python
temperatura = 26
if temperatura > 25:
    print("Activar sistema de refrigeración.")

```

### 2. Estructura Doble (`if...else`)

Establece una ruta de ejecución alternativa cuando la condición principal se evalúa como `False`.

```python
temperatura = 18
if temperatura > 25:
    print("Activar refrigeración.")
else:
    print("Temperatura dentro del rango nominal.")

```

### 3. Estructura Múltiple (`if...elif...else`)

Permite encadenar múltiples escenarios. El término `elif` es la contracción de *else if*. Python analiza las expresiones secuencialmente de arriba a abajo y **ejecuta exclusivamente el primer bloque cuya condición sea verdadera**, omitiendo el resto.

```python
nota = 78

if nota >= 90:
    print("Sobresaliente")
elif nota >= 70:
    print("Notable")
elif nota >= 50:
    print("Aprobado")
else:
    print("Suspenso")

```

💡 **Encadenamiento directo de comparaciones:**
En Java o C#, validar un rango numérico requiere la combinación de dos condiciones con operadores lógicos: `if (nota >= 70 && nota < 90)`. Python permite simplificar esta sintaxis escribiendo una **comparación matemática continua**, lo que incrementa la legibilidad y reduce la redundancia sintáctica:

```python
if 70 <= nota < 90:
    print("El alumno ha obtenido una calificación de Notable.")

```

## 📚 Coincidencia de Patrones Moderna: `match-case`

Introducida en Python 3.10, la estructura `match-case` evoluciona el clásico `switch-case` de lenguajes como C++ o Java, aportando una sintaxis de coincidencia de patrones (*pattern matching*) más limpia y expresiva.

### Ventajas técnicas de `match-case`:

* **Sin caída de casos (*no fall-through*):** Omitir el comando `break` no provoca que la ejecución se desborde al siguiente caso. Python finaliza la estructura tras ejecutar la coincidencia encontrada.
* **Agrupamiento mediante tuberías (`|`):** Varios valores pueden desencadenar la misma acción utilizando el operador `|` (O lógico en patrones).
* **Patrón comodín de captura (`_`):** La barra baja actuará como el caso por defecto (equivalente a `default` en Java).

```python
dia_semana = "Sábado"

match dia_semana:
    case "Lunes" | "Martes" | "Miércoles" | "Jueves" | "Viernes":
        print("Jornada laborable. Módulo en desarrollo.")
    case "Sábado" | "Domingo":
        print("Fin de semana. Mantenimiento programado.")
    case _:
        print("Día no identificado en el calendario.")

```

## 📊 Criterios de Selección: `if` frente a `match-case`

| Criterio | `if...elif...else` | `match-case` |
| --- | --- | --- |
| **Tipo de condiciones** | Evaluaciones lógicas complejas, desigualdades (`>`, `<`, `>=`), rangos o múltiples variables. | Coincidencias de valores exactos, cadenas específicas o estructuras de datos fijas. |
| **Estructura** | Evaluaciones arbitrarias de múltiples expresiones booleanas independientes. | Centrado en el análisis de valor o patrón de un objeto/variable individual. |
| **Legibilidad** | Apto para flujos con decisiones dinámicas. | Estructura limpia para enrutadores de peticiones, comandos de consola o estados fijos. |

### 💡 Ejemplo 1: Cuándo usar `if...elif...else`

Úsalo cuando necesites evaluar **rangos numéricos**, **múltiples variables a la vez** o **condiciones dinámicas**:

```python
# Múltiples variables y comparaciones de rango
espacio_usado_gb = 450.0
es_premium = False

if es_premium and espacio_usado_gb < 1000.0:
    estado = "Cuenta Premium OK"
elif not es_premium and espacio_usado_gb >= 500.0:
    estado = "Cuota Gratuita Excedida"
else:
    estado = "Uso Estándar"

```

### 💡 Ejemplo 2: Cuándo usar `match-case`

Úsalo cuando compares **una sola variable** contra una **lista de opciones o comandos cerrados**:

```python
# Evaluación de una única variable con opciones fijas
comando = "PAUSE"

match comando:
    case "START" | "RESUME":
        print("Iniciando servicio...")
    case "PAUSE" | "STOP":
        print("Deteniendo servicio...")
    case _:
        print("Comando desconocido")

```

## ⚙️ Limpieza y Normalización de Entradas de Texto

Al validar entradas introducidas por usuarios o sistemas externos mediante `input()` o APIs, es habitual recibir caracteres inesperados, inconsistencias en mayúsculas/minúsculas o espacios accidentales. Se deben aplicar métodos de saneamiento antes de ejecutar la comparación condicional:

```python
cadena_cruda = "   aDmInIsTrAdOr   "

# 1. Eliminar espacios en blanco en ambos extremos
limpia = cadena_cruda.strip()         # "aDmInIsTrAdOr"

# 2. Convertir a minúsculas para comparaciones insensibles a mayúsculas
minusculas = limpia.lower()            # "administrador"

# 3. Convertir a mayúsculas para códigos o constantes
mayusculas = limpia.upper()            # "ADMINISTRADOR"

# 4. Encadenamiento directo de métodos (Method Chaining)
rol_normalizado = cadena_cruda.strip().lower()  # "administrador"

```

## 💻 Ejemplo de código

Crea un archivo denominado `gestor_pedidos.py` para analizar el procesamiento de órdenes en una API backend según su importe y tipo de cliente:

```python
# Entrada simulada de usuario o API
tipo_cliente = "  pReMiUm  "
monto_compra = 250.0

# Normalización del texto de entrada
cliente_clean = tipo_cliente.strip().lower()

# 1. Determinación de descuento por volumen y tipo de cliente (if...elif...else)
if cliente_clean == "premium" and monto_compra >= 200.0:
    descuento = 0.20  # 20% de descuento
elif cliente_clean == "premium" or monto_compra >= 300.0:
    descuento = 0.10  # 10% de descuento
elif 100.0 <= monto_compra < 200.0:
    descuento = 0.05  # 5% de descuento
else:
    descuento = 0.0

precio_final = monto_compra * (1 - descuento)

# 2. Selección del método de envío con match-case según el cliente
match cliente_clean:
    case "vip" | "premium":
        envio = "Envío Prioritario Express (Gratuito)"
    case "estándar" | "estandar":
        envio = "Envío Estándar (3-5 días laborables)"
    case _:
        envio = "Envío Normal con Cargo por Gestión"

print(f"Tipo de Cliente: {cliente_clean.capitalize()}")
print(f"Monto Original: {monto_compra}€")
print(f"Descuento Aplicado: {int(descuento * 100)}%")
print(f"Precio Final: {precio_final}€")
print(f"Método de Envío: {envio}")

```

## 📝 Ejercicio guiado

Implementaremos un validador para un cortafuegos que gestiona el tráfico web analizando protocolos y estados de conexión.

```python
protocolo_red = "   HTTPS   "
puerto_origen = 443
conexion_segura = False

# Normalización
protocolo_clean = protocolo_red.strip().upper()

# 1. Evaluación del protocolo con match-case
match protocolo_clean:
    case "HTTP":
        puerto_esperado = 80
        conexion_segura = False
    case "HTTPS":
        puerto_esperado = 443
        conexion_segura = True
    case "SSH":
        puerto_esperado = 22
        conexion_segura = True
    case _:
        puerto_esperado = -1

# 2. Validación del estado del tráfico con if...elif...else
if puerto_esperado == -1:
    estado_trafico = "RECHAZADO: Protocolo no reconocido o no soportado."
elif puerto_origen != puerto_esperado:
    estado_trafico = f"ALERTA: El protocolo {protocolo_clean} no coincide con el puerto {puerto_origen}."
elif conexion_segura:
    estado_trafico = f"PERMITIDO: Tráfico cifrado correcto sobre {protocolo_clean} (Puerto {puerto_origen})."
else:
    estado_trafico = f"PERMITIDO CON ADVERTENCIA: Tráfico no cifrado detectado sobre {protocolo_clean}."

print(f"Protocolo evaluado: {protocolo_clean}")
print(f"Resultado de inspección: {estado_trafico}")

```

🔍 **Explicación:**

* `.strip().upper()` garantiza que variaciones como `"https "`, `" Https"` o `"https"` se traten como `"HTTPS"`.
* La estructura `match-case` asigna rápidamente las variables asociadas a cada protocolo conocido.
* Las bifurcaciones `if...elif...else` analizan las anomalías de seguridad antes de autorizar el puerto.

📌 **Prueba:** Cambia `protocolo_red = "HTTP"` y `puerto_origen = 443` para comprobar cómo el cortafuegos detecta la incoherencia entre el protocolo y el puerto seleccionado.
