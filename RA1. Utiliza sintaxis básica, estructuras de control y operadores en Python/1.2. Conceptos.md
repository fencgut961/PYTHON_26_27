## 📚 Operadores relacionales y encadenamiento

Los operadores de comparación analizan la relación entre dos datos u objetos y devuelven **siempre un valor booleano (`True` o `False`)**.

| Operador | Significado | Ejemplo (`a = 15`, `b = 20`) | Resultado |
| --- | --- | --- | --- |
| `==` | Igual a | `a == b` | `False` |
| `!=` | Distinto de | `a != b` | `True` |
| `>` | Mayor que | `a > b` | `False` |
| `<` | Menor que | `a < b` | `True` |
| `>=` | Mayor o igual que | `a >= 15` | `True` |
| `<=` | Menor o igual que | `b <= 20` | `True` |

### Encadenamiento de comparaciones (Sintaxis Matemática)

En lenguajes de programación como Java o C#, validar si una variable se encuentra en un determinado rango numérico exige dos expresiones unidas por un operador lógico:

```java
// Código Java / C#
if (edad >= 18 && edad <= 30) { ... }

```

En Python, es posible **encadenar comparaciones** imitando la notación matemática, lo que optimiza la legibilidad del código sin pérdida de rendimiento:

```python
edad = 22

# Evaluación de rango en una única expresión limpia
en_rango = 18 <= edad <= 30
print(en_rango)  # Devuelve True

```

## ⚙️ Valor frente a Identidad: `==` frente a `is`

A nivel de gestión de memoria, es crítico diferenciar la equivalencia del contenido de la identidad del objeto.

* **`==` (Equivalencia de valor):** Compara si los **datos almacenados** son iguales. Es el equivalente al método `.equals()` en Java.
* **`is` (Identidad de memoria):** Compara si dos etiquetas apuntan **al mismo objeto físico** en el *heap* (misma dirección de memoria). Equivale al operador `==` sobre referencias en Java.

Python dispone de la función integrada `id(objeto)` para consultar la dirección de memoria única que el sistema asigna a cada objeto.

```python
# Dos estructuras de datos creadas de forma independiente
lista_a = [1, 2, 3]
lista_b = [1, 2, 3]
lista_c = lista_a  # Apunta a la misma dirección física que lista_a

print(lista_a == lista_b)  # True  -> Contenido idéntico
print(lista_a is lista_b)  # False -> Son dos objetos independientes en memoria
print(lista_a is lista_c)  # True  -> Apuntan exactamante al mismo objeto

# Inspección de referencias en memoria:
print(id(lista_a))  # Ejemplo: 140728492023168
print(id(lista_b))  # Ejemplo: 140728492023808 (Dirección distinta)
print(id(lista_c))  # Ejemplo: 140728492023168 (Misma dirección que lista_a)

```

💡 **Tip de rendimiento (Interning en CPython):**
Para optimizar memoria, Python reutiliza internamente ciertos objetos inmutables básicos, como enteros pequeños (entre `-5` y `256`) o cadenas cortas sin espacios. Por eso, `x = 10` e `y = 10` devolverán `True` ante `x is y`, mientras que para números más grandes o listas creará objetos independientes. Para comprobar valores en código de producción, **usa siempre `==**`, reservando `is` casi en exclusiva para la comprobación de variables nulas (`variable is None`).

## 📚 Operadores lógicos y evaluación en cortocircuito

Los operadores lógicos evalúan y combinan expresiones booleanas.

| Operador | Significado | Comportamiento |
| --- | --- | --- |
| `and` | Y lógico | Devuelve un resultado afirmativo únicamente si **todas** las condiciones son verdaderas. |
| `or` | O lógico | Devuelve un resultado afirmativo si **al menos una** de las condiciones es verdadera. |
| `not` | Negación | Invierte el estado booleano actual (`True` pasa a `False` y viceversa). |

### Evaluación en cortocircuito (*Short-Circuit*)

Python evalúa las expresiones lógicas de izquierda a derecha de forma perezosa (*lazy evaluation*): interrumpe la comprobación en cuanto el resultado final queda garantizado matemáticamente.

* **Cortocircuito en `and`:** Si la primera condición es `False`, el resultado global será `False` obligatoriamente. Python **no evalúa** las condiciones siguientes.
* **Cortocircuito en `or`:** Si la primera condición es `True`, el resultado global será `True` obligatoriamente. Python **no evalúa** las condiciones siguientes.

👉 **Valores Truthy y Falsy en Python:**
Cualquier objeto en Python puede ser evaluado dentro de un contexto booleano. Se consideran **`Falsy`** (falsos de forma implícita):

* El valor nulo `None`.
* El número `0` y `0.0`.
* Cadenas, listas, diccionarios o colecciones vacías (`""`, `[]`, `{}`).

Cualquier otro valor se considera **`Truthy`** (`True`).

### Retorno de operandos reales

En Python, los operadores `and` y `or` no devuelven estrictamente un tipo `bool`, sino **el valor del último operando evaluado** que determinó la resolución:

```python
# 'or' se detiene en la primera cadena porque es Truthy y devuelve ese texto
usuario = "Aragorn" or "Invitado"
print(usuario)  # "Aragorn"

# Al ser la primera cadena Falsy (""), 'or' se ve obligado a evaluar y devolver la segunda
usuario_defecto = "" or "Invitado"
print(usuario_defecto)  # "Invitado"

```

## 💻 Ejemplo de código

Crea un archivo denominado `validacion_acceso.py` para analizar el comportamiento combinado de operadores relacionales, identidad y evaluación en cortocircuito:

```python
# Simulación de sesión de usuario y niveles de permiso
rol_usuario = "ADMIN"
nivel_seguridad = 4
token_sesion = "xyz123"
cuenta_bloqueada = False

# 1. Encadenamiento de comparaciones y evaluación de permisos
nivel_valido = 1 <= nivel_seguridad <= 5
es_admin = rol_usuario == "ADMIN"

# Acceso permitido: Debe tener nivel válido, ser ADMIN y NO estar bloqueado
acceso_concedido = nivel_valido and es_admin and not cuenta_bloqueada
print(f"¿Acceso al panel concedido?: {acceso_concedido}")

# 2. Uso de 'is' para verificar variables nulas
respuesta_api = None
datos_disponibles = respuesta_api is not None
print(f"¿Hay datos de la API cargados?: {datos_disponibles}")

# 3. Asignación con fallback usando 'or' (Truthy / Falsy)
nombre_entrada = ""
nombre_pantalla = nombre_entrada or "Usuario Anónimo"
print(f"Nombre en interfaz: {nombre_pantalla}")

```

## 📝 Ejercicio guiado

Implementaremos un filtro de validación de puertos e IP para un cortafuegos simulado:

```python
# Datos simulados de una petición entrante
ip_origen = "192.168.1.50"
puerto_destino = 8080
ip_lista_negra = "10.0.0.1"

# 1. Comprobar si el puerto está en rango permitido (8000 a 9000)
puerto_valido = 8000 <= puerto_destino <= 9000

# 2. Validar que la IP no sea nula y no coincida con la lista negra
ip_segura = (ip_origen is not None) and (ip_origen != ip_lista_negra)

# 3. Permitir tráfico si cumple ambas restricciones
trafico_permitido = puerto_valido and ip_segura

print(f"Puerto en rango (8000-9000): {puerto_valido}")
print(f"IP Verificada: {ip_segura}")
print(f"¿Tráfico autorizado?: {trafico_permitido}")

```

🔍 **Explicación:**

* La expresión `8000 <= puerto_destino <= 9000` evalúa el rango del puerto de forma continua.
* La verificación `ip_origen is not None` evita errores de ejecución garantizando que la referencia a la IP existe antes de comparar su valor con `!=`.
* Si `puerto_valido` resulta ser `False`, la evaluación en cortocircuito ignora la comprobación de `ip_segura`.

📌 **Prueba:** Cambia `puerto_destino = 443` y comprueba cómo el sistema rechaza la conexión al estar fuera del rango permitido.
