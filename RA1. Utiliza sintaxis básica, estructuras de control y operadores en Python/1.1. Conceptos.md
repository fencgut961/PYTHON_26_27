## 📚 Alteración del flujo en bucles: break y continue

Durante la ejecución estándar de un bucle, las iteraciones transcurren hasta agotar la secuencia (en bucles `for`) o hasta que la condición lógica se evalúa como falsa (en bucles `while`). Sin embargo, en el desarrollo real a menudo es necesario alterar este comportamiento predeterminado.

Python proporciona dos sentencias clave para gestionar estas interrupciones:

* **`break` (Interrupción inmediata):** Abandona el bucle por completo. Ninguna línea posterior del bloque del bucle se ejecuta y el programa pasa a la siguiente instrucción fuera del bucle.
* **`continue` (Salto de iteración):** Omite el resto del código de la vuelta actual y salta inmediatamente a la siguiente iteración del bucle.

```python
# Demostración de break
for num in range(1, 6):
    if num == 3:
        break  # Interrumpe el bucle al llegar a 3
    print(f"Número: {num}")

# Demostración de continue
for num in range(1, 6):
    if num == 3:
        continue  # Salta la impresión del número 3
    print(f"Número: {num}")

```

💡 **Buenas prácticas:** Usa `break` y `continue` de forma justificada y limpia. Abusar de estas sentencias en bucles muy extensos puede dificultar la lectura y el seguimiento de la lógica del código.

## ⚙️ Estructuras avanzadas de control y comparativa

### La cláusula opcional `else` en bucles

Python permite añadir un bloque `else` al final de un bucle `for` o `while`. El código dentro de este bloque **solo se ejecuta si el bucle completa todas sus iteraciones de forma natural**, es decir, sin haber sido interrumpido por una sentencia `break`.

```python
usuarios = ["admin", "marta", "carlos"]
buscado = "sofia"

for usuario in usuarios:
    if usuario == buscado:
        print("Usuario encontrado.")
        break
else:
    print("Usuario no registrado en el sistema.")

```

👉 **Nota:** Si el bucle ejecuta un `break`, el bloque `else` se omite por completo.

### Patrón `while True` (Bucle Infinito Controlado)

Es una estructura común en aplicaciones de consola para mantener un programa activo (por ejemplo, mostrando un menú) hasta que el usuario decida salir explícitamente.

---

## 📊 Comparativa técnica: break vs continue

| Sentencia | Efecto en el bucle | Siguientes líneas de la iteración | Impacto en bloque `else` |
| --- | --- | --- | --- |
| **`break`** | Rompe el bucle y sale de él. | Se ignoran en esta y en las siguientes vueltas. | **Cancela** la ejecución del `else`. |
| **`continue`** | Pasa a la siguiente iteración. | Se ignoran solo en la vuelta actual. | **No afecta** a la ejecución del `else`. |

## 💻 Ejemplo de código

Crea un archivo llamado `control_procesos.py` para verificar el comportamiento de ambas sentencias en el procesamiento de una lista de paquetes:

```python
# Lista de paquetes con sus pesos en kg (valores negativos indican datos corruptos)
paquetes = [12.5, 4.0, -1.0, 25.0, 0.0, 50.0]
LIMITE_PESO = 40.0

print("--- INICIO DE PROCESAMIENTO ---")

for peso in paquetes:
    # 1. Ignorar datos corruptos o vacíos
    if peso <= 0:
        print("⚠️ Advertencia: Paquete no válido omitido.")
        continue  # Salta a la siguiente vuelta

    # 2. Detener proceso si se excede el peso de seguridad
    if peso > LIMITE_PESO:
        print(f"🚨 Alerta: Paquete de {peso}kg supera el límite permitido ({LIMITE_PESO}kg).")
        print("Deteniendo cinta transportadora...")
        break  # Interrumpe el bucle por completo

    print(f"✅ Paquete de {peso}kg procesado correctamente.")

print("--- FIN DEL PROCESO ---")

```

## 📝 Ejercicio guiado

Procesaremos las lecturas de una serie de sensores térmicos. Ignoraremos lecturas erróneas (`None`) y detendremos el análisis de emergencia si la temperatura supera los 80°C.

```python
lecturas_sensor = [22.5, 25.0, None, 45.8, 85.2, 30.1]

print("Iniciando monitoreo térmico...")

for lectura in lecturas_sensor:
    # 1. Filtrar lecturas nulas
    if lectura is None:
        print("Sensor no responde (lectura OMITIDA).")
        continue

    # 2. Evaluar umbral de peligro
    if lectura > 80.0:
        print(f"🔥 CRÍTICO: {lectura}°C detectados. Activando protocolo de parada.")
        break

    print(f"Temperatura estable: {lectura}°C")
else:
    print("Todas las lecturas se completaron sin alertas críticas.")

```

🔍 **Explicación:**

* `lectura is None`: Identifica datos faltantes y usa `continue` para saltar la iteración sin interrumpir el análisis global.
* `lectura > 80.0`: Detecta un valor crítico y usa `break` para salir del bucle inmediatamente.
* `else`: Se ejecutaría únicamente si ninguna lectura superara los 80.0°C.

📌 **Prueba:** Modifica el valor `85.2` por `50.0` en la lista `lecturas_sensor` y ejecuta el programa de nuevo para observar cómo se activa el bloque `else`.
