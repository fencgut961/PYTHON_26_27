## 📚 Concepto de variable y modelo de memoria

Una **variable** es un nombre simbólico asociado a un valor en la memoria. Permite almacenar, reutilizar y modificar información durante la ejecución del programa.

### Modelo de etiquetas frente a cajas (Java/C#)

En lenguajes de tipado estático como Java, una variable representa un espacio físico fijo en memoria (*caja*). En Python:

* **Las variables son etiquetas (referencias):** Los valores se alojan de forma independiente en la memoria (*heap*). La variable es una etiqueta que apunta hacia esa dirección de memoria.
* **Tipado dinámico e implícito:** No se declara el tipo. El intérprete lo deduce según el objeto asignado. Una misma etiqueta puede apuntar a distintos tipos a lo largo del tiempo.

```python
personaje = "Aragorn"  # 'personaje' apunta a un objeto str
nivel = 15            # 'nivel' apunta a un objeto int

# Reasignación dinámica:
nivel = "Nivel Máximo" # Ahora apunta a un str; el entero 15 queda libre para el recolector de basura

```

💡 **Buenas prácticas de nombrado (PEP 8):**

* Usa la convención **`snake_case`** (`puntos_vida`, `ataque_base`).
* No inicies variables con números (`jugador_1` es válido; `1_jugador` es sintácticamente erróneo).
* Utiliza nombres descriptivos en lugar de identificadores genéricos (`x`, `temp`).
* Las **constantes** se escriben en **`MAYÚSCULAS`** (`MAX_VIDA = 100`).

## ⚙️ Tipos de datos primarios y conversión (Casting)

Python dispone de cuatro tipos integrados esenciales:

* **`str` (cadena de texto):** Secuencia de caracteres delimitada por comillas. Ej. `"Mago"`.
* **`int` (entero):** Números enteros sin límite rígido de precisión en memoria. Ej. `85`.
* **`float` (decimal):** Números en coma flotante bajo el estándar IEEE 754. Ej. `1.25`.
* **`bool` (booleano):** Representa estados lógicos: `True` o `False`.

👉 **Nota:** Internamente, `bool` es una subclase de `int`. Aritméticamente, `True` equivale a `1` y `False` a `0`.

### Entrada de datos y casting

La función `input("mensaje")` detiene la ejecución y devuelve siempre la información introducida como un objeto **`str`**. Para operar matemáticamente, debemos realizar un *casting* explícito:

* **`int(x)`**: Convierte a entero. Si `x` contiene caracteres no numéricos, eleva la excepción `ValueError`.
* **`float(x)`**: Convierte a número decimal.
* **`str(x)`**: Convierte cualquier objeto a su representación en texto.
* **`bool(x)`**: Devuelve `False` ante valores vacíos (`""`, `0`, `0.0`), y `True` en cualquier otro caso.

## 📚 Slicing de cadenas y operadores

El **slicing** (rebanado) extrae una subcadena a partir de los índices de posición de sus caracteres (comenzando en el índice `0`).

```python
subcadena = cadena[inicio:fin]

```

* **`inicio`**: Índice inicial (incluido).
* **`fin`**: Índice final (**excluido**).

Si tenemos el texto `"NIVEL-095"`:

```text
N  I  V  E  L  -  0  9  5
0  1  2  3  4  5  6  7  8

```

* `cadena[0:5]` extrae `"NIVEL"` (índices 0 al 4).
* `cadena[6:9]` o `cadena[6:]` extrae `"095"` (desde el índice 6 hasta el final).

### Operadores Aritméticos

| Operador | Operación | Ejemplo | Resultado |
| --- | --- | --- | --- |
| `+` | Suma | `5 + 3` | `8` |
| `-` | Resta | `10 - 4` | `6` |
| `*` | Multiplicación | `4 * 2` | `8` |
| `/` | División real | `5 / 2` | `2.5` *(devuelve siempre `float`)* |
| `//` | División entera | `5 // 2` | `2` *(trunca decimales)* |
| `%` | Módulo | `5 % 2` | `1` *(resto de la división)* |
| `**` | Potencia | `2 ** 3` | `8` |

👉 **Asignación compuesta:** Permite condensar operaciones sobre la misma variable (`x += 3` equivale a `x = x + 3`; `x *= 2` equivale a `x = x * 2`).

## 💻 Ejemplo de código

Crea un archivo llamado `estadisticas.py` para verificar el comportamiento del casting y la reasignación:

```python
# Definición de constantes y variables
MAX_VIDA = 100
nombre_jugador = "Guerrero"
vida_actual = 80.5

# Operaciones aritméticas y asignación compuesta
dano_recibido = 15.0
vida_actual -= dano_recibido  # Equivalente a: vida_actual = vida_actual - dano_recibido

# Verificación del estado mediante casting
porcentaje_vida = (vida_actual / MAX_VIDA) * 100
esta_vivo = vida_actual > 0

print(f"Jugador: {nombre_jugador}")
print(f"Vida restante: {vida_actual}/{MAX_VIDA} ({int(porcentaje_vida)}%)")
print(f"¿Sigue con vida?: {esta_vivo}")

```

## 📝 Ejercicio guiado

Procesaremos un código identificador de un producto almacenado como texto para separar sus componentes y calcular su precio final con IVA.

```python
# Formato del código recibido: "PROD-8542-49.99" (Categoría-ID-Precio)
codigo_producto = "PROD-8542-49.99"

# 1. Extraer secciones usando Slicing
categoria = codigo_producto[0:4]
id_producto = codigo_producto[5:9]
precio_str = codigo_producto[10:]

# 2. Convertir el precio a float para calcular el IVA (21%)
precio_base = float(precio_str)
precio_final = precio_base * 1.21

# 3. Mostrar el reporte en consola
print(f"Categoría: {categoria}")
print(f"ID Producto: {id_producto}")
print(f"Precio base: {precio_base}€")
print(f"Precio con IVA (21%): {round(precio_final, 2)}€")

```

🔍 **Explicación:**

* `codigo_producto[0:4]` toma los primeros 4 caracteres (`"PROD"`).
* `codigo_producto[10:]` extrae desde la posición 10 hasta el final de la cadena (`"49.99"`).
* `float(precio_str)` transforma el texto extraído en un valor numérico ejecutable para la multiplicación.

📌 **Prueba:** Cambia la variable `codigo_producto` a `"ITEM-1020-15.50"` y ejecuta de nuevo el archivo para comprobar la extracción dinámica.
