## 📚 El bucle `for` y la iteración sobre secuencias

En lenguajes como Java o C#, un bucle `for` tradicional requiere definir explícitamente una variable de control, una condición de permanencia y un paso de incremento (`for (int i = 0; i < N; i++)`).

En Python, el bucle `for` opera como un **foreach**: itera directamente sobre los elementos de cualquier objeto *iterable* (cadenas de texto, rangos numéricos, listas o tuplas) sin necesidad de gestionar índices de forma manual.

```python
for elemento in secuencia:
    # Bloque de código ejecutado por cada elemento

```

* **`elemento`**: Variable temporal que toma automáticamente la referencia del valor actual en cada vuelta del bucle.
* **`secuencia`**: Objeto iterable que proporciona los datos de forma secuencial.

### Iteración sobre cadenas de texto (`str`)

Dado que las cadenas de texto son secuencias ordenadas de caracteres inmutables, el bucle `for` permite examinarlas carácter a carácter:

```python
modulo = "PYTHON"

for caracter in modulo:
    print(f"Procesando carácter: {caracter}")

```

## ⚙️ El objeto `range()`: Generación de rangos numéricos

Cuando se requiere repetir un bloque de código un número determinado de veces, Python utiliza la función integrada **`range()`**.

🔍 **Mecanismo interno de memoria (Lazy Evaluation):**
En Python 3, `range()` no crea una lista con todos los números cargados simultáneamente en la memoria RAM. Genera un **objeto de rango inmutable** que calcula cada número bajo demanda (*evaluación perezosa* o *lazy evaluation*). Esto permite iterar sobre rangos de millones de elementos con un consumo de memoria constante de $O(1)$.

`range()` acepta hasta **tres parámetros**:

1. **`range(stop)`**: Genera números enteros desde `0` hasta `stop - 1` (el límite superior es exclusivo).
```python
for i in range(5):
    print(i)  # Imprime: 0, 1, 2, 3, 4

```


2. **`range(start, stop)`**: Genera números enteros desde `start` hasta `stop - 1`.
```python
for i in range(10, 15):
    print(i)  # Imprime: 10, 11, 12, 13, 14

```


3. **`range(start, stop, step)`**: Genera números aplicando un incremento (o decremento) constante definido por `step`.
```python
# Iteración con paso positivo (números pares)
for i in range(2, 11, 2):
    print(i)  # Imprime: 2, 4, 6, 8, 10

# Iteración con paso negativo (cuenta atrás)
for i in range(5, 0, -1):
    print(i)  # Imprime: 5, 4, 3, 2, 1

```

## 📚 El bucle `while` y la repetición condicional

El bucle `while` ejecuta de forma iterativa un bloque de código **mientras una condición booleana se mantenga como `True**`.

Se utiliza cuando **no se conoce de antemano el número exacto de iteraciones**, ya que la finalización del bucle depende de un evento dinámico en tiempo de ejecución (una respuesta de red, la entrada de un usuario o el cambio de estado de una variable).

```python
while condicion:
    # Bloque de código ejecutado mientras la condición sea True

```

### Ejemplo con contador explicito

```python
intentos = 1

while intentos <= 3:
    print(f"Intento de conexión #{intentos}")
    intentos += 1  # Incremento obligatorio para modificar la condición

```

⚠️ **Prevención de bucles infinitos:**
Si la condición del bucle `while` no cambia nunca a `False`, el programa entrará en un ciclo infinito de ejecución, bloqueando el hilo de trabajo y saturando un núcleo de la CPU. Para evitarlo:

1. Garantiza que la variable que controla la condición cambie de valor dentro del cuerpo del bucle.
2. Asegúrate de que la condición de parada sea alcanzable bajo cualquier escenario de datos.

📌 *Sugerencia de consola:* Si ejecutas accidentalmente un bucle infinito en el terminal, puedes interrumpir el proceso enviando la señal `SIGINT` mediante la combinación de teclas `Ctrl + C`.

## 📊 Criterios de Selección: `for` frente a `while`

| Criterio | Bucle `for` | Bucle `while` |
| --- | --- | --- |
| **Nº de iteraciones** | Conocido o acotado por la longitud de una colección/rango. | Indeterminado o dependiente de un evento dinámico externo. |
| **Control de parada** | Automático (al agotar la secuencia o el rango). | Manual (mediante la reevaluación de una condición lógica). |
| **Uso habitual** | Recorrer colecciones, procesar lotes de datos, rangos fijos. | Menús interactivos, reintentos de conexión, escuchas de red (*daemons*). |
| **Riesgo de bloqueo** | Mínimo (el generador siempre tiene un fin definido). | Alto (si se omite la actualización de la condición de parada). |

## 💻 Ejemplo de código

Crea un archivo denominado `procesador_lotes_servidor.py` para simular el procesamiento de lotes de transacciones y un protocolo de reintentos de red:

```python
# 1. Bucle FOR: Procesamiento de un lote fijo de 5 paquetes de datos
print("=== INICIANDO PROCESAMIENTO DE LOTE DE PAQUETES ===")
for id_paquete in range(101, 106):
    print(f"Procesando Paquete ID: #{id_paquete} -> OK")

# 2. Bucle WHILE: Reintentos de conexión a base de datos con límite de fallos
print("\n=== VERIFICANDO CONEXIÓN CON SERVIDOR PRINCIPAL ===")
conexion_establecida = False
intento_actual = 1
max_reintentos = 3

while not conexion_establecida and intento_actual <= max_reintentos:
    print(f"Estableciendo handshake con la BD (Intento {intento_actual}/{max_reintentos})...")
    
    # Simulación: La conexión se logra en el intento 3
    if intento_actual == 3:
        conexion_establecida = True
        print("¡Conexión establecida con éxito!")
    else:
        print("Fallo de tiempo de espera (Timeout). Reintentando...")
        intento_actual += 1

# Verificación de estado final
if not conexion_establecida:
    print("ERROR CRÍTICO: No se pudo conectar con el servidor backend.")

```

## 📝 Ejercicio guiado

Implementaremos un analizador de trazas de registro de seguridad que escanea una cadena de texto en busca de intentos fallidos de autenticación:

```python
# Cadena que simula una ráfaga de logs de autenticación ('S' = Success, 'F' = Failure)
trama_logs = "SFFSFFFSS"

totales = 0
fallos = 0

# 1. Recorrer cada evento individual mediante un bucle for
for evento in trama_logs:
    totales += 1
    if evento == "F":
        fallos += 1

# 2. Calcular la tasa de fallo
porcentaje_fallos = (fallos / totales) * 100

print(f"Eventos Analizados: {totales}")
print(f"Accesos Denegados: {fallos}")
print(f"Tasa de Error: {porcentaje_fallos:.1f}%")

# 3. Determinar si el sistema está bajo ataque mediante una condición
if porcentaje_fallos > 50.0:
    print("ESTADO: ALERTA DE BLOQUEO - Tasa de fallos elevada.")
else:
    print("ESTADO: Tráfico dentro de parámetros normales.")

```

🔍 **Explicación:**

* El bucle `for` extrae secuencialmente cada carácter (`"S"` o `"F"`) de la cadena `trama_logs`.
* Las variables acumuladoras `totales` y `fallos` registran las métricas en cada iteración.
* Al finalizar el recorrido completo de la cadena, se evalúa la proporción de fallos sin necesidad de bucles adicionales.
