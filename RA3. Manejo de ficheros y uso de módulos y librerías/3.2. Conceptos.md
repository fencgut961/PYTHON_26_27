## 1. ¿Qué es un Módulo?

Un **módulo** es un archivo de Python (con extensión `.py`) que agrupa funciones, variables, constantes y clases bajo un mismo propósito para facilitar la reutilización de código y el mantenimiento modular.

### Procedencia de los módulos en Python

1. **Módulos Estándar:** Vienen preinstalados de forma nativa con el intérprete de Python (ej: `math`, `os`, `sys`, `random`, `json`, `datetime`).
2. **Módulos Externos:** Desarrollados por la comunidad de código abierto y alojados en el índice oficial **PyPI** (*Python Package Index*). Se instalan mediante `pip`.
3. **Módulos Personalizados:** Archivos `.py` creados por el desarrollador para estructurar un proyecto en distintas capas.

---

### Sintaxis y Variaciones de Importación

Para incorporar el código de un módulo a nuestro script, disponemos de tres variantes sintácticas:

#### A. Importar el módulo completo (`import`)

Mantiene el espacio de nombres del módulo, obligando a anteponer su nombre seguido de un punto para acceder a sus miembros:

```python
import math

print(math.sqrt(16))  # Salida: 4.0

```

#### B. Importar elementos específicos (`from ... import ...`)

Aísla únicamente las funciones o constantes requeridas, permitiendo invocarlas directamente sin prefijo:

```python
from math import pi, sqrt

print(sqrt(25))  # Salida: 5.0
print(pi)        # Salida: 3.141592653589793

```

#### C. Asignar un alias o renombrar (`import ... as ...`)

Asigna un identificador abreviado al módulo, una práctica habitual para agilizar la escritura en librerías extensas:

```python
import math as m

print(m.factorial(5))  # Salida: 120

```

## 2. Módulos Estándar Esenciales de la Industria

Analizaremos en profundidad tres de los módulos nativos más utilizados en el desarrollo backend, la administración de sistemas y la automatización industrial:

### A. Módulo `math` (Operaciones Científicas)

Proporciona acceso a funciones matemáticas de alta precisión y constantes físicas y numéricas:

* `math.sqrt(x)`: Devuelve la raíz cuadrada en coma flotante de $x$.
* `math.factorial(x)`: Calcula el factorial de un entero positivo $x$.
* `math.pow(x, y)`: Eleva $x$ a la potencia $y$ (devuelve un `float`).
* `math.pi` y `math.e`: Constantes numéricas fundamentales ($\pi \approx 3.14159$ y $e \approx 2.71828$).

```python
import math

radio = 4.5
area_sensor = math.pi * math.pow(radio, 2)
print(f"Área del círculo de cobertura: {area_sensor:.4f} m²")

```

### B. Módulo `os` (Interacción con el Sistema Operativo)

Permite interactuar de forma nativa con el sistema de archivos del sistema operativo anfitrión:

* `os.getcwd()`: Obtiene la ruta física del directorio de trabajo actual (*Current Working Directory*).
* `os.listdir(ruta)`: Devuelve una lista con los archivos y carpetas contenidos en la ruta especificada. Usar `"."` apunta al directorio actual.
* `os.mkdir(nombre)`: Crea un nuevo directorio en el sistema. Lanza una excepción `FileExistsError` si la carpeta ya existe.

```python
import os

print("Ubicación actual del script:", os.getcwd())
print("Archivos en el directorio activo:")
for elemento in os.listdir("."):
    print(f" - {elemento}")

```

### C. Módulo `sys` (Interacción con el Intérprete)

Permite inspeccionar y manipular parámetros de bajo nivel del entorno de ejecución de Python:

* `sys.version`: Devuelve una cadena con la versión exacta de Python en ejecución.
* `sys.platform`: Indica la plataforma del sistema operativo (`"win32"` para Windows, `"darwin"` para macOS, `"linux"` para distribuciones Linux).
* `sys.argv`: Lista que contiene los argumentos pasados por línea de comandos al ejecutar el script.

```python
import sys

print("Plataforma operativa:", sys.platform)
print("Versión del intérprete:", sys.version)

```

## 3. Consumo de Librerías Externas con `pip`

Cuando la biblioteca estándar no es suficiente para resolver una necesidad técnica específica, recurrimos a librerías externas.

### ¿Qué es `pip`?

`pip` (*Package Installer for Python*) es el gestor de paquetes oficial de Python. Se encarga de buscar, descargar, instalar y actualizar dependencias desde el repositorio central **PyPI**, resolviendo automáticamente los conflictos entre versiones.

### Comandos de consola indispensables

```bash
# Instalar un paquete de PyPI
pip install nombre_del_paquete

# Desinstalar un paquete instalado
pip uninstall nombre_del_paquete

# Listar todos los paquetes instalados en el entorno activo
pip list

# Guardar la lista de dependencias del proyecto en un archivo
pip freeze > requirements.txt

# Instalar todas las dependencias listadas en un archivo
pip install -r requirements.txt

```

## 4. Consumo Real de una API de Red con `requests`

Una de las librerías externas más utilizadas en la industria es **`requests`**, diseñada para realizar peticiones HTTP/HTTPS de forma intuitiva y segura.

### Instalación desde la terminal

```bash
pip install requests

```

### Integración de peticiones HTTP con control de errores

```python
import requests

url_api = "https://api.github.com"

try:
    print(f"Iniciando petición GET a: {url_api}")
    # Petición HTTP GET con tiempo límite de respuesta
    respuesta = requests.get(url_api, timeout=5)
    
    # Comprobación del código de estado HTTP (200 indica respuesta exitosa)
    print("Código de estado HTTP:", respuesta.status_code)
    print("Tamaño del cuerpo recibido:", len(respuesta.text), "caracteres.")
    
    # Muestra de la cabecera de la respuesta truncada
    print("\nCabecera de la respuesta (Primeros 150 caracteres):")
    print(respuesta.text[:150])

except requests.exceptions.ConnectionError:
    print("❌ Error de red: Imposible conectar con el servidor. Revisa tu acceso a internet.")
except requests.exceptions.Timeout:
    print("❌ Error de red: La solicitud superó el tiempo máximo de espera (Timeout).")
except Exception as e:
    print(f"❌ Error inesperado al procesar la petición: {e}")

```

## 💻 5. Ejemplo Integrador Completo

El siguiente script audita la salud del sistema combinando módulos del entorno local (`os`, `sys`, `math`) con consultas a una API externa (`requests`) para verificar conectividad y geolocalización de red:

```python
"""
Módulo de auditoría de entorno de ejecución y diagnóstico de red.
Utiliza módulos estándar de Python y la librería externa requests.
"""

import math
import os
import sys
import requests


def auditar_entorno_local() -> dict:
    """Recopila información del sistema operativo, versión de Python y estado del directorio.

    :return: Diccionario con la telemetría del entorno local
    """
    archivos_locales = os.listdir(".")
    total_archivos = len(archivos_locales)
    
    # Cálculo del factor de ocupación usando math.log2 como métrica de prueba
    factor_ocupacion = math.log2(total_archivos) if total_archivos > 0 else 0.0

    return {
        "so": sys.platform,
        "python_version": sys.version.split()[0],
        "directorio_trabajo": os.getcwd(),
        "total_archivos": total_archivos,
        "factor_ocupacion": round(factor_ocupacion, 2)
    }


def verificar_conectividad_api(url: str) -> bool:
    """Comprueba la disponibilidad de un endpoint HTTP remoto.

    :param url: Dirección URL a verificar
    :return: True si el servidor responde con un estado 200, False en caso contrario
    """
    try:
        respuesta = requests.get(url, timeout=3)
        return respuesta.status_code == 200
    except requests.exceptions.RequestException:
        return False


# --- EJECUCIÓN PRINCIPAL ---
if __name__ == "__main__":
    print("=== INFORMACIÓN DEL ENTORNO DE EJECUCIÓN ===")
    telemetria = auditar_entorno_local()
    
    for clave, valor in telemetria.items():
        print(f" - {clave.replace('_', ' ').title()}: {valor}")

    print("\n=== VERIFICACIÓN DE RED ===")
    target_url = "https://httpbin.org/get"
    estado_red = verificar_conectividad_api(target_url)
    
    if estado_red:
        print(f"✅ Conexión establecida correctamente con {target_url}")
    else:
        print(f"❌ Fallo de conectividad o tiempo de espera agotado con {target_url}")

```

## 📝 6. Ejercicio de Diagnóstico

Analiza el siguiente fragmento de código e identifica los **3 errores lógicos o sintácticos**:

```python
# Tarea A: Intento de uso de una función no importada o mal cualificada
import math

resultado = sqrt(64) + pi

# Tarea B: Fallo al crear un directorio sin controlar su existencia previa
import os

os.mkdir("logs_auditoria")
print("Directorio de logs creado con éxito.")

# Tarea C: Petición HTTP sin definir un timeout y captura genérica incorrecta
import requests

try:
    res = requests.get("https://api.empresa.com/v1/health")
    data = res.json()
except Exception:
    print("Ocurrió un error")
except requests.exceptions.Timeout:
    print("La petición excedió el tiempo límite")

```

### 💡 Respuestas de Diagnóstico

1. 🚨 **Error de Espacio de Nombres (`NameError`) (Tarea A):** Al importar con `import math`, las funciones y constantes quedan encapsuladas dentro del espacio de nombres `math`. Invocar `sqrt(64)` o `pi` directamente lanzará `NameError: name 'sqrt' is not defined`. La sintaxis correcta es `math.sqrt(64) + math.pi`, o bien importar explícitamente: `from math import sqrt, pi`.
2. ⚠️ **Excepción no Controlada por Directorio Existente (Tarea B):** Si la carpeta `"logs_auditoria"` ya existe en el directorio de trabajo, `os.mkdir()` lanzará una excepción unhandled de tipo `FileExistsError`. Debe usarse un bloque `try-except` o verificar previamente con `if not os.path.exists("logs_auditoria"):`.
3. ❌ **Ausencia de `timeout` y Jerarquía de Excepciones Inválida (Tarea C):**
* Petición insegura: `requests.get()` sin el parámetro `timeout` puede colgar indefinidamente el programa si el servidor no responde.
* Bloque inalcanzable (*Unreachable code*): Colocar `except Exception:` antes de `except requests.exceptions.Timeout:` provoca que la excepción específica jamás sea ejecutada, ya que la captura genérica `Exception` intercepta cualquier error antes.
