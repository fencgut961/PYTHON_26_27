## 1. Introducción a los Ficheros en Python

Un **fichero** es un conjunto de datos estructurados almacenados de forma permanente en una unidad física. En programación se dividen en dos categorías principales:

* **Ficheros de Texto:** Contienen caracteres legibles organizados en líneas (`.txt`, `.csv`, `.json`, `.log`). Se codifican habitualmente en UTF-8.
* **Ficheros Binarios:** Contienen bytes puros sin interpretar (`.png`, `.exe`, `.zip`, archivos serializados).

Para interactuar con cualquier archivo en Python se utiliza la función integrada:

```python
open(nombre, modo, encoding)

```

### Modos de apertura esenciales

| Modo | Nombre | Descripción |
| --- | --- | --- |
| `"r"` | **Lectura** (*Read*) | Abre el archivo solo para lectura. Lanza `FileNotFoundError` si el archivo no existe. |
| `"w"` | **Escritura** (*Write*) | Abre el archivo para escribir. **Sobrescribe y borra** el contenido anterior. Crea el archivo si no existe. |
| `"a"` | **Anexar** (*Append*) | Abre el archivo para añadir datos al final, **preservando** el contenido existente. Crea el archivo si no existe. |
| `"rb"` / `"wb"` | **Binario** (*Binary Read/Write*) | Lee o escribe bytes crudos directamente, sin decodificación de texto. |

> **Recomendación de oro:** Al trabajar con archivos de texto, especifica siempre el parámetro `encoding="utf-8"`. Esto evita problemas de incompatibilidad con tildes, eñes y caracteres especiales entre distintos sistemas operativos (Windows, macOS o Linux).

## 2. Lectura Eficiente de Ficheros

Python ofrece cuatro enfoques para extraer información de un archivo abierto en modo lectura (`"r"`):

### A. Método `.read()`

Lee todo el contenido del archivo y lo devuelve como una única cadena de texto (`str`).

```python
archivo = "registro_accesos.log"
modo = "r"

with open(archivo, modo, encoding="utf-8") as f:
    contenido = f.read()
    print(contenido)

```

### B. Método `.readline()`

Lee una única línea del archivo (hasta encontrar el salto de línea `\n`) y la devuelve como `str`.

```python
with open(archivo, modo, encoding="utf-8") as f:
    primera_linea = f.readline()
    print("Cabecera:", primera_linea.strip())

```

### C. Método `.readlines()`

Carga todas las líneas del archivo en una lista (`list`), donde cada elemento es una línea de texto.

```python
with open(archivo, modo, encoding="utf-8") as f:
    lista_lineas = f.readlines()
    print(f"El archivo tiene {len(lista_lineas)} registros.")

```

### D. Iteración Directa (La opción recomendada)

Recorre el archivo directamente dentro de un bucle `for`. Esta alternativa no carga todo el fichero en memoria RAM de golpe, sino que procesa línea a línea bajo demanda (*lazy evaluation*).

```python
with open(archivo, modo, encoding="utf-8") as f:
    for linea in f:
        # Usamos .strip() para eliminar saltos de línea extra
        print("Registro procesado:", linea.strip())

```

## 3. Escritura y Anexado Seguro

Para escribir información en disco se utiliza el método `.write(texto)`. A diferencia de `print()`, el método `.write()` **no añade automáticamente un salto de línea**, por lo que se debe incluir el carácter `\n` explícitamente.

### Ejemplo de Escritura (`"w"`):

```python
archivo_salida = "alertas_criticas.txt"
modo_escritura = "w"

with open(archivo_salida, modo_escritura, encoding="utf-8") as f:
    f.write("ALERTA: Acceso no autorizado detectado en servidor DB\n")
    f.write("Nivel: CRÍTICO\n")

```

### Ejemplo de Anexado (`"a"`):

```python
archivo_historico = "historico_alertas.txt"
modo_anexar = "a"

with open(archivo_historico, modo_anexar, encoding="utf-8") as f:
    f.write("05-09-2026 10:45:32 - IP 192.168.1.150 bloqueada provisionalmente\n")

```

## 4. Gestión de Recursos con la Sentencia `with`

El enfoque tradicional obligaba a cerrar manualmente el fichero mediante `.close()`:

```python
f = open("datos.txt", "r")
# ... procesamiento de datos ...
f.close()  # Obligatorio para liberar el recurso en el SO

```

Si ocurriese una excepción antes de ejecutar `.close()`, el recurso quedaría bloqueado en memoria, pudiendo provocar fugas o corrupción de datos.

El **Administrador de Contexto** (`with`) resuelve este problema:

```python
with open("datos.txt", "r", encoding="utf-8") as f:
    contenido = f.read()

# Fuera del bloque indentado, el archivo se ha cerrado automáticamente
print("¿Archivo cerrado?:", f.closed)  # Retorna True

```

El bloque `with` asegura el cierre inmediato del archivo al finalizar la ejecución o si surge una excepción dentro de él.

## 5. Robustez en Producción: Manejo de Excepciones

Las operaciones de E/S (*I/O*) en disco están expuestas a fallos externos al programa (archivos inexistentes, permisos denegados, espacio insuficiente). Para evitar interrupciones no controladas (*crashes*), se emplean estructuras **`try-except`**:

* `FileNotFoundError`: Lanzado si se intenta abrir un archivo que no existe en el disco.
* `PermissionError`: Lanzado si el sistema operativo deniega el acceso al recurso.

```python
archivo_seguridad = "config/firewall.rules"
modo_lectura = "r"

try:
    with open(archivo_seguridad, modo_lectura, encoding="utf-8") as f:
        configuracion = f.read()
        print("Reglas del cortafuegos cargadas con éxito.")
except FileNotFoundError:
    print("❌ Error crítico: No se encontró el archivo 'firewall.rules'. Cargando configuración por defecto...")
except PermissionError:
    print("❌ Error de seguridad: Permisos insuficientes para acceder a las reglas del cortafuegos.")
except Exception as e:
    print(f"❌ Error inesperado al procesar el archivo: {e}")

```

## 💻 6. Ejemplo Integrador Completo

El siguiente script procesa un archivo de registros de auditoría de seguridad, extrae los eventos críticos y genera un informe de salida controlado con manejo de excepciones:

```python
"""
Módulo de procesamiento y filtrado de logs de auditoría.
Demuestra lectura/escritura segura de ficheros con context managers y excepciones.
"""

LOG_ENTRADA = "auditoria_red.log"
LOG_SALIDA = "alertas_criticas.txt"


def filtrar_eventos_criticos(ruta_origen: str, ruta_destino: str) -> int:
    """Lee un fichero de log, extrae registros CRITICOS y los guarda en un archivo de salida.

    :param ruta_origen: Ruta del archivo de entrada a auditar
    :param ruta_destino: Ruta del archivo donde se escribirán las alertas
    :return: Número de alertas críticas extraídas y guardadas
    """
    alertas_encontradas = 0

    try:
        # Apertura simultánea de entrada (lectura) y salida (anexado)
        with open(ruta_origen, "r", encoding="utf-8") as f_in, \
             open(ruta_destino, "a", encoding="utf-8") as f_out:

            for linea in f_in:
                if "CRITICO" in linea:
                    f_out.write(linea)
                    alertas_encontradas += 1

    except FileNotFoundError:
        print(f"❌ Error: El archivo fuente '{ruta_origen}' no existe.")
    except PermissionError:
        print(f"❌ Error: Sin permisos de escritura/lectura sobre los archivos.")
    except Exception as e:
        print(f"❌ Excepción no controlada durante la auditoría: {e}")

    return alertas_encontradas


# --- EJECUCIÓN PRINCIPAL ---
if __name__ == "__main__":
    total = filtrar_eventos_criticos(LOG_ENTRADA, LOG_SALIDA)
    print(f"Proceso finalizado. Alertas registradas: {total}")

```

## 📝 7. Ejercicio de Diagnóstico

Analiza el siguiente fragmento de código e identifica los **3 errores lógicos o sintácticos**:

```python
# Tarea A: Abrir un archivo en modo escritura para leer su contenido
archivo_datos = "servidores.txt"
with open(archivo_datos, "w", encoding="utf-8") as f:
    contenido = f.read()

# Tarea B: Escribir una lista de IPs sin manejar saltos de línea ni modo correcto
ips = ["192.168.1.1", "10.0.0.1", "172.16.0.1"]
f_out = open("ips_bloqueadas.txt", "r")
for ip in ips:
    f_out.write(ip)

# Tarea C: Capturar excepciones de lectura sin la jerarquía adecuada
try:
    with open("config.json", "r") as f:
        config = f.read()
except Exception as e:
    print("Error general")
except FileNotFoundError:
    print("Archivo no encontrado")

```

### 💡 Respuestas de Diagnóstico

1. 🚨 **Pérdida de Datos y Error de Operación (Tarea A):** Abrir el archivo con el modo `"w"` trunca (borra inmediatamente) todo su contenido. Además, intentar invocar `.read()` sobre un archivo abierto en modo escritura lanzará un `io.UnsupportedOperation: not readable`. Para leer sin borrar, se debe usar `"r"`.
2. ⚠️ **Modo Incorrecto, Falta de Saltos de Línea y Recurso Abierto (Tarea B):**
* Se abre el archivo en modo `"r"` (lectura) e intenta ejecutar `.write()`, lo que lanzará `io.UnsupportedOperation: not writable`. Debe usarse `"w"` o `"a"`.
* `f_out.write(ip)` concatenará todas las IPs en una sola línea sin espacios (`192.168.1.110.0.0.1...`). Falta añadir `\n`.
* Se utiliza `open()` sin la sentencia `with`, dejando el fichero sin cerrar si no se llama explícitamente a `.close()`.


3. ❌ **Bloque Except Inalcanzable (Tarea C):** Colocar `except Exception:` antes de `except FileNotFoundError:` provoca que la captura genérica intercepte cualquier tipo de error primero, haciendo que el bloque específico `FileNotFoundError` sea inalcanzable (*unreachable code*). Los errores específicos siempre deben declararse antes de las excepciones genéricas.
