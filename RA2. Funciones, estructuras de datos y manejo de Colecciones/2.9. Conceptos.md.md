## 1. ¿Qué es la función `zip()`?

La función nativa `zip()` toma dos o más colecciones iterables (listas, tuplas, conjuntos) y las une elemento a elemento según su posición física, actuando como una cremallera. Genera un **iterador** que produce tuplas ordenadas posicionalmente.

```text
Lista A: [ "192.168.1.50" , "10.0.0.99" ]
             │                 │
             ▼                 ▼
zip()  ──>  ( "192.168.1.50", "HTTPS" ) , ( "10.0.0.99", "SSH" )
             ▲                 ▲
             │                 │
Lista B: [  "HTTPS"       ,   "SSH"    ]

```

### Sintaxis y Funcionamiento Básico

```python
# Listas independientes pero asociadas por su orden de captura
ips = ["192.168.1.50", "10.0.0.99"]
protocolos = ["HTTPS", "SSH"]

# Sincronizamos las listas en un iterador
conexion_zip = zip(ips, protocolos)

# Para evaluar todo el contenido de una vez, lo convertimos a lista
print(list(conexion_zip))
# Salida: [('192.168.1.50', 'HTTPS'), ('10.0.0.99', 'SSH')]

```

## 2. Recorrer Múltiples Colecciones al Mismo Tiempo

El valor principal de `zip()` reside en su integración con los bucles `for`. Permite iterar por varias listas en paralelo con una sintaxis limpia, eliminando el patrón frágil de iterar por índice (`range(len(lista))`).

### A. Sincronización de Dos Colecciones

```python
marcas_tiempo = ["10:00:05", "10:01:22", "10:02:40"]
ips_origen = ["192.168.1.15", "185.220.101.5", "10.0.0.4"]

for tiempo, ip in zip(marcas_tiempo, ips_origen):
    print(f"[{tiempo}] Tráfico detectado desde la IP: {ip}")

```

### B. Sincronización de Tres o Más Colecciones

`zip()` permite pasar un número indeterminado de iterables en la misma llamada:

```python
timestamps = ["12:30", "12:31"]
ips = ["1.1.1.1", "8.8.8.8"]
puertos = [53, 53]
estados = ["BLOQUEADO", "PERMITIDO"]

for t, ip, port, status in zip(timestamps, ips, puertos, estados):
    print(f"Hora: {t} | IP: {ip}:{port} -> Estado: {status}")

```

## 3. Comportamiento con Listas de Diferente Tamaño

Cuando las colecciones pasadas a `zip()` no tienen la misma longitud, **el emparejamiento se detiene automáticamente al agotar la lista más corta**. Los elementos sobrantes de las listas más largas se ignoran sin lanzar una excepción.

```python
nombres = ["Analista_A", "Analista_B", "Analista_C"]
guardias_activas = [True, False]  # Contiene solo dos elementos

for analista, activa in zip(nombres, guardias_activas):
    print(f"{analista} de guardia activa: {activa}")

# Salida:
# Analista_A de guardia activa: True
# Analista_B de guardia activa: False
# ('Analista_C' se omite porque la segunda lista ha finalizado)

```

> **Nota:** Este truncamiento previene errores de tipo `IndexError`. Si requieres mantener los elementos sobrantes rellenando los huecos faltantes con un valor por defecto, puedes recurrir a `itertools.zip_longest()`.

## 4. Uso de `zip()` con Diccionarios

Al aplicar `zip()` directamente sobre diccionarios, Python itera por defecto únicamente sobre sus **claves**:

```python
servidores_ips = {"SRV-Web": "192.168.1.10", "SRV-DB": "192.168.1.20"}
servidores_os = {"SRV-Web": "Linux Ubuntu", "SRV-DB": "Windows Server"}

for clave_a, clave_b in zip(servidores_ips, servidores_os):
    print(f"Claves sincronizadas: {clave_a} <-> {clave_b}")

```

Para correlacionar tanto las claves como los valores de múltiples diccionarios, se debe llamar explícitamente al método `.items()` desempaquetando la estructura dentro del bucle:

```python
for (srv_a, ip), (srv_b, sistema_operativo) in zip(servidores_ips.items(), servidores_os.items()):
    print(f"Servidor: {srv_a} | IP: {ip} | S.O: {sistema_operativo}")

```

## 5. Deshacer un zip (Unpacking con el operador `*`)

Para separar una colección de tuplas agrupadas en sus listas originales independientes, se utiliza el operador de desempaquetado `*` junto a `zip()`.

Este patrón distribuye las tuplas internas como argumentos individuales en una nueva llamada a `zip()`, reagrupando los elementos por su posición de origen:

```python
# Registros previamente agrupados en tuplas
alertas_consolidadas = [
    ("10:15", "SSH_ATTACK"),
    ("10:18", "MALWARE_DET"),
    ("10:20", "PORT_SCAN")
]

# Desempaquetado y reagrupación
timestamps, firmas = zip(*alertas_consolidadas)

print(timestamps)  # ('10:15', '10:18', '10:20')
print(firmas)      # ('SSH_ATTACK', 'MALWARE_DET', 'PORT_SCAN')

```

## 💻 6. Ejemplo Integrador Completo

El siguiente script consolida telemetría de red dispersa en múltiples colecciones paralelas, procesa eventos correlacionados con `zip()` y separa informes procesados mediante desempaquetado:

```python
"""
Módulo de correlación de eventos de red e inspección de tráfico.
Demuestra iteración sincrónica con zip(), dict comprehensions y desempaquetado.
"""

# Fuentes de datos en paralelo
TIMESTAMPS = ["2026-09-08 11:00:01", "2026-09-08 11:00:04", "2026-09-08 11:00:10"]
IPS_ORIGEN = ["192.168.1.45", "10.0.0.12", "172.16.0.99"]
PUERTOS_DESTINO = [80, 22, 443]
ACCIONES = ["PERMITIR", "BLOQUEAR", "PERMITIR"]


def analizar_trafico_sincronizado(
    tiempos: list, ips: list, puertos: list, acciones: list
) -> list:
    """Combina métricas paralelas de red y filtra eventos bloqueados.

    :param tiempos: Marcas de tiempo asociadas a cada evento
    :param ips: Direcciones IP de origen
    :param puertos: Puertos de destino evaluados
    :param acciones: Veredicto aplicado por el firewall
    :return: Lista de tuplas filtradas con eventos de riesgo
    """
    eventos_riesgo = []

    # Iteración síncrona sobre cuatro colecciones a la vez
    for t, ip, puerto, accion in zip(tiempos, ips, puertos, acciones):
        if accion == "BLOQUEAR" or puerto == 22:
            eventos_riesgo.append((t, ip, puerto, accion))

    return eventos_riesgo


# --- EJECUCIÓN PRINCIPAL ---
 incidentes = analizar_trafico_sincronizado(
    TIMESTAMPS, IPS_ORIGEN, PUERTOS_DESTINO, ACCIONES
)

print("--- ALERTAS DE TRÁFICO SUSPECTED ---")
for inc in incidentes:
    print(f"Timestamp: {inc[0]} | IP: {inc[1]} | Puerto: {inc[2]} | Acción: {inc[3]}")

# Desempaquetar los incidentes filtrados en secuencias individuales
if incidentes:
    tiempos_inc, ips_inc, puertos_inc, acciones_inc = zip(*incidentes)
    print("\n--- RESUMEN FORENSE ---")
    print("IPs bajo investigación:", set(ips_inc))
    print("Puertos comprometidos:", list(puertos_inc))

```

## 📝 7. Ejercicio de Diagnóstico

Analiza el siguiente fragmento de código e identifica los **3 errores lógicos o sintácticos**:

```python
# Tarea A: Intentar reocupar un iterador zip consumido sin convertirlo previamente
ips = ["10.0.0.1", "10.0.0.2"]
puertos = [80, 443]
zip_eventos = zip(ips, puertos)

lista_a = list(zip_eventos)
lista_b = list(zip_eventos)  # ¿Qué contendrá lista_b?

# Tarea B: Desempaquetar pares clave-valor de diccionarios sin invocar .items()
dict_a = {"A": 1, "B": 2}
dict_b = {"X": 10, "Y": 20}

for (k1, v1), (k2, v2) in zip(dict_a, dict_b):
    print(v1, v2)

# Tarea C: Intentar desempaquetar una lista vacía con zip(*...)
registro_vacio = []
tiempos, ips = zip(*registro_vacio)

```

### 💡 Respuestas de Diagnóstico

1. ⚠️ **Agotamiento del Iterador (Tarea A):** `zip()` devuelve un iterador de un solo uso. Tras llamar a `list(zip_eventos)`, el iterador queda agotado, por lo que `lista_b` será una lista vacía `[]`.
2. 🚨 **Excepción de Desempaquetado (Tarea B):** Al pasar diccionarios directamente a `zip()`, este solo itera sobre sus claves (cadenas de texto), no sobre pares tupla. Intentar hacer `(k1, v1)` lanzará `ValueError: not enough values to unpack`. Debe usarse `zip(dict_a.items(), dict_b.items())`.
3. ❌ **Excepción `TypeError` en Desempaquetado Vacío (Tarea C):** La expresión `zip(*[])` equivale a llamar a `zip()` sin argumentos, lo que devuelve un iterador vacío. Intentar asignarlo a dos variables (`tiempos, ips`) lanzará `ValueError: not enough values to unpack (expected 2, got 0)`.
