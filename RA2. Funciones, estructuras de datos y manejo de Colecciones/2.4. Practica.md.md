# 🔹 Práctica 2.4: Spotify Premium Sync & Global Volume Controller

---

## 📖 Contexto del proyecto

En los servicios de streaming multimedia como **Spotify**, la sincronización de estado entre clientes (dispositivo activo, nivel de suscripción y volumen global) requiere una arquitectura sólida de manejo de variables.

Para evitar errores de corrupción de estado o acoplamiento indeseado, los desarrolladores deben comprender a la perfección la diferencia entre el **ámbito global** y el **ámbito local**, el fenómeno del **sombreado de variables (*shadowing*)** y las ventajas de diseñar funciones desacopladas mediante parámetros y valores de retorno.

---

## 🎯 El reto

Desarrollarás un script ejecutable e interactivo en Python guardado como **`ra2_act4_spotify_sync.py`** que simule el centro de control y sincronización de reproductor de Spotify.

El programa mantendrá el estado global de la sesión y permitirá interactuar con él a través de un menú en consola, demostrando prácticamente el comportamiento del ciclo de vida de las variables y evaluando tanto el uso de la sentencia `global` como la refactorización mediante funciones puras.

---

## 🚫 Restricciones del ejercicio (Patrón Anti-IA)

👉 Para garantizar la evaluación objetiva del concepto de ámbito (*scope*):

* Se deben definir explícitamente las tres variables globales indicadas al inicio del script.
* La función `mostrar_estado_reproductor()` **no puede** utilizar la palabra clave `global` ni recibir parámetros.
* La función `actualizar_suscripcion_premium()` **debe utilizar obligatoriamente** la palabra clave `global`.
* La función `cambiar_dispositivo_con_sombreado()` **no puede** utilizar la palabra clave `global` para forzar la demostración del efecto de sombreado (*shadowing*).
* La función `ajustar_volumen_seguro()` **no puede** acceder a ninguna variable global; debe resolver el cálculo exclusivamente con sus parámetros y devolver el resultado mediante `return`.
* Cada función debe incorporar un **Docstring multilínea (PEP 257)**.
* El código debe cumplir rigurosamente el estándar **PEP 8**.

---

## 🛠️ Requisitos del programa

### 1. Variables Globales Iniciales

En la raíz del script (ámbito global), declara las siguientes tres variables:

* `USUARIO_PREMIUM` (`bool`): Valor inicial `False`.
* `DISPOSITIVO_ACTIVO` (`str`): Valor inicial `"PC"`.
* `VOLUMEN_GLOBAL` (`int`): Valor inicial `50`.

---

### 2. Definición de Funciones Requeridas

#### A. `mostrar_estado_reproductor()`

* **Propósito:** Lee directamente del ámbito global (`G`) el estado actual del reproductor y lo imprime con formato estético.
* **Firmas y Reglas:** Sin parámetros, sin `return`, **sin usar la palabra clave `global**` (solo lectura).

#### B. `actualizar_suscripcion_premium()`

* **Propósito:** Modifica de forma persistente la variable global `USUARIO_PREMIUM` asignándole `True`.
* **Firmas y Reglas:** Sin parámetros, sin `return`, **requiere uso obligatorio de `global USUARIO_PREMIUM**`.

#### C. `cambiar_dispositivo_con_sombreado(nuevo_dispositivo)`

* **Propósito:** Demuestra el efecto de sombreado (*variable shadowing*).
* **Parámetro:** `nuevo_dispositivo` (`str`).
* **Lógica:** Asigna `DISPOSITIVO_ACTIVO = nuevo_dispositivo` **sin incluir la instrucción `global**`. Muestra un mensaje en consola con el valor local asignado. Al finalizar, la variable global original permanecerá inalterada.

#### D. `ajustar_volumen_seguro(volumen_actual, incremento)`

* **Propósito:** Representa la buena práctica de diseño desacoplado para modificar estado.
* **Parámetros:** `volumen_actual` (`int`), `incremento` (`int`, positivo para subir, negativo para bajar).
* **Lógica:** Calcula el nuevo volumen limiting el resultado estrictamente en el rango de **0 a 100** (si es menor a 0 fija 0; si es mayor a 100 fija 100).
* **Retorno:** Devuelve el nuevo nivel de volumen calculado (`int`). **Prohibido usar `global` o modificar variables globales dentro de esta función**.

---

### 3. Programa Principal (Menú Interactivo)

El punto de entrada principal del script ejecutará un bucle `while True` que desplegará el siguiente menú interactivo:

```text
=== SPOTIFY SYNC MANAGER ===
1. Mostrar estado del reproductor
2. Activar suscripción Premium (Prueba de variable global)
3. Cambiar dispositivo activo (Prueba de sombreado de variable)
4. Ajustar volumen (Prueba de función parametrizada con retorno seguro)
5. Salir

```

* **Opción 1:** Invoca a `mostrar_estado_reproductor()`.
* **Opción 2:** Invoca a `actualizar_suscripcion_premium()`.
* **Opción 3:** Lee el nombre del dispositivo con `input()`, aplica `.strip()`, e invoca a `cambiar_dispositivo_con_sombreado()`.
* **Opción 4:** Lee la variación deseada (ej. `20` o `-15`), la convierte a `int`, invoca a `ajustar_volumen_seguro(VOLUMEN_GLOBAL, variacion)` y **reasigna explícitamente el resultado retornado** sobre la variable global `VOLUMEN_GLOBAL`.
* **Opción 5:** Muestra un mensaje de despedida y rompe el bucle con `break`.
