## 1. Concepto y Propiedades de la Clase `dict`

Un **diccionario** en Python es una colección de datos ordenada (a partir de Python 3.7+), mutable y asociativa que almacena la información estructurada en parejas **clave-valor** (*key-value*).

```text
               Clave (Key) ──►  "INC-1024"       "192.168.1.105"        443
                               ┌─────────────┬───────────────────┬──────────────┐
              Mapa de Registro:│  "ticket"   │    "ip_origen"    │   "puerto"   │
                               └─────────────┴───────────────────┴──────────────┘
               Valor (Value)──►  "INC-1024"       "192.168.1.105"        443

```

### Características Fundamentales:

* **Asociativo:** Los elementos no se organizan mediante índices numéricos enteros (`0, 1, 2...`), sino a través de **claves descriptivas únicas**.
* **Claves Inmutables (*Hashable*):** Las claves deben ser obligatoriamente de un tipo de dato inmutable (`str`, `int`, `float`, `tuple`). Esto permite búsquedas en tiempo constante $O(1)$. Las listas o diccionarios no pueden ser claves.
* **Valores Flexibles:** Los valores asociados no tienen restricciones de tipo; pueden almacenar enteros, listas, tuplas, funciones u otros diccionarios.
* **Mutable:** Es posible añadir, actualizar o eliminar pares clave-valor sin cambiar la identidad del objeto en memoria.

```python
# Instanciación de diccionarios
inventario_vacio = {}  # Sintaxis preferida
servidor_soc = {
    "host": "SRV-WEB-01",
    "ip": "10.0.0.1",
    "puertos_abiertos": [80, 443],
    "activo": True
}

```

## 2. Acceso Seguro y Control de Excepciones

Para consultar el valor asociado a una clave existen dos estrategias de lectura:

### A. Acceso Directo por Corchetes `[]`

Accede directamente al valor. Si la clave especificada no existe en el diccionario, el intérprete interrumpirá la ejecución lanzando una excepción `KeyError`.

```python
servidor = {"host": "SRV-WEB-01", "ip": "10.0.0.1"}

print(servidor["host"])  # Salida: 'SRV-WEB-01'
# print(servidor["puerto"])  # ❌ KeyError: 'puerto'

```

### B. Acceso Seguro mediante `.get()`

Es la técnica defensiva estándar. Permite buscar una clave y, si esta no existe, retorna `None` (o un valor alternativo predeterminado) evitando la interrupción del programa.

```python
servidor = {"host": "SRV-WEB-01", "ip": "10.0.0.1"}

# Retorna None si la clave no existe
puerto = servidor.get("puerto")  # Salida: None

# Retorna un valor por defecto parametrizado
puerto_seguro = servidor.get("puerto", 80)  # Salida: 80
print(f"Puerto configurado: {puerto_seguro}")

```

> ⚠️ **Práctica Recomendada:** Utiliza `[]` únicamente cuando estés seguro de la existencia de la clave o requieras que la ausencia de datos fuerce un fallo explícito; utiliza `.get()` para procesar entradas externas o configuraciones opcionales.

## 3. Manipulación de Datos (CRUD)

La clase `dict` permite realizar modificaciones directas sobre sus registros de forma eficiente.

### A. Inserción y Modificación

La sintaxis para asignar un valor es idéntica tanto para actualizar como para crear claves:

* Si la clave **ya existe**, sobrescribe su valor actual.
* Si la clave **no existe**, se crea la nueva pareja clave-valor.

```python
usuario = {"username": "m_torres", "rol": "Analista"}

# Modificación de clave existente
usuario["rol"] = "Administrador SOC"

# Inserción de nueva clave
usuario["ultimo_login"] = "2026-09-08"

print(usuario)
# Salida: {'username': 'm_torres', 'rol': 'Administrador SOC', 'ultimo_login': '2026-09-08'}

```

### B. Eliminación de Registros

* **Instrucción `del`:** Elimina la clave y su valor del diccionario. Lanza `KeyError` si la clave no existe.
* **Método `.pop(key, default)`:** Extrae la clave, la elimina del diccionario y **retorna su valor**. Si la clave no existe y se proporciona un segundo argumento, este se devuelve en lugar de lanzar una excepción.
* **Método `.clear()`:** Elimina la totalidad de los elementos contenidos.

```python
alerta = {"id": "AL-99", "severidad": "Baja", "origen": "Firewall"}

# Eliminación directa
del alerta["origen"]

# Extracción y eliminación con .pop()
nivel_sev = alerta.pop("severidad")  # Devuelve "Baja" y elimina la clave

# Extracción segura con valor por defecto
estado = alerta.pop("estado", "No asignado")  # Devuelve "No asignado" sin error

print(alerta)  # Salida: {'id': 'AL-99'}

```

## 4. Métodos Integrados para Inspección e Iteración

Para recorrer un diccionario mediante bucles `for`, la clase `dict` proporciona tres métodos que devuelven vistas dinámicas de los datos:

| Método | Retorno / Propósito | Ejemplo de Uso |
| --- | --- | --- |
| **`.keys()`** | Colección iterable con todas las **claves**. | `for k in dict.keys():` |
| **`.values()`** | Colección iterable con todos los **valores**. | `for v in dict.values():` |
| **`.items()`** | Colección de **tuplas `(clave, valor)**`. | `for k, v in dict.items():` |

```python
config_red = {
    "gateway": "192.168.1.1",
    "dns": "8.8.8.8",
    "subnet": "255.255.255.0"
}

# 1. Iterar sobre claves
for clave in config_red.keys():
    print(f"Parámetro: {clave}")

# 2. Iterar sobre valores
for valor in config_red.values():
    print(f"Dirección IP: {valor}")

# 3. Iterar sobre claves y valores (Patrón idóneo con desempaquetado)
for clave, valor in config_red.items():
    print(f"Configuración [{clave}] -> {valor}")

```

## 5. Estructuras Complejas: Diccionarios Anidados

En el desarrollo de software profesional y consumo de APIs (como respuestas en formato JSON), los datos se estructuran de forma jerárquica anidando diccionarios dentro de otros diccionarios.

```python
# Mapeo de infraestructura Cloud
infraestructura = {
    "srv-prod-01": {
        "so": "Ubuntu 24.04 LTS",
        "recursos": {"cpu": 8, "ram": "32GB"},
        "estado": "ACTIVO"
    },
    "srv-db-01": {
        "so": "Debian 12",
        "recursos": {"cpu": 16, "ram": "64GB"},
        "estado": "MANTENIMIENTO"
    }
}

# Acceso encadenado por claves secuenciales
ram_db = infraestructura["srv-db-01"]["recursos"]["ram"]
print(f"Memoria RAM asignada a DB: {ram_db}")  # Salida: 64GB

# Modificación en estructuras anidadas
infraestructura["srv-prod-01"]["estado"] = "DETENIDO"

```

## 💻 6. Ejemplo Integrador Completo

El siguiente script administra la asignación de tickets de incidentes de ciberseguridad, aplicando consultas seguras, actualizaciones CRUD e iteraciones compuestas:

```python
"""
Módulo de gestión e inspección de tickets para el Centro de Operaciones de Seguridad (SOC).
Demuestra el uso defensivo de diccionarios, iteración con .items() y anidación.
"""

# --- BASE DE DATOS DE TICKETS DE SEGURIDAD ---
gestor_incidentes = {
    "INC-801": {
        "origen": "192.168.1.45",
        "tipo": "Fuerza Bruta SSH",
        "severidad": "ALTA",
        "atendido": False
    },
    "INC-802": {
        "origen": "10.0.0.120",
        "tipo": "Escaneo de Puertos",
        "severidad": "MEDIA",
        "atendido": True
    }
}


def procesar_ticket(base_datos: dict, id_ticket: str) -> None:
    """Actualiza el estado de un ticket e imprime su reporte formal.

    :param base_datos: Diccionario principal con el registro de incidentes.
    :param id_ticket: Identificador único del ticket a actualizar.
    """
    # Consulta defensiva con .get() sobre el diccionario principal
    ticket = base_datos.get(id_ticket)

    if not ticket:
        print(f"⚠️ Error: El ticket {id_ticket} no existe en el sistema.")
        return

    # Actualización de campo en el diccionario anidado
    ticket["atendido"] = True
    ticket["resolucion"] = "IP Mitigada en Firewall"

    print(f"=== REPORTE DE INCIDENTE {id_ticket} ===")
    for campo, valor in ticket.items():
        print(f" | {campo.capitalize()}: {valor}")
    print("=" * 35)


# --- EJECUCIÓN PRINCIPAL ---
# 1. Agregar un nuevo ticket dinámicamente
gestor_incidentes["INC-803"] = {
    "origen": "172.16.0.88",
    "tipo": "Inyección SQL",
    "severidad": "CRÍTICA",
    "atendido": False
}

# 2. Procesar ticket mediante función
procesar_ticket(gestor_incidentes, "INC-803")

```

## 📝 Ejercicio de Diagnóstico

Analiza el siguiente fragmento de código e identifica los **3 errores lógicos o de ejecución** relacionados con el manejo de diccionarios:

```python
# Tarea A: Intentar usar una lista como clave de un diccionario
lista_puertos = [80, 443]
registro_firewall = {lista_puertos: "Regla HTTP/HTTPS"}

# Tarea B: Consultar una clave inexistente esperando un manejo seguro
configuracion = {"host": "127.0.0.1", "puerto": 8080}
modo = configuracion["modo_depuracion"]

# Tarea C: Intentar iterar sobre pares clave-valor con sintaxis errónea
for clave, valor in configuracion.values():
    print(clave, valor)

```

### Respuestas de Diagnóstico:

1. **Excepción `TypeError` por Clave No-Hashable (Tarea A):** Las listas son mutables y no-hashables (`unhashable type: 'list'`). Para solucionar esto, la clave debe convertirse a una tupla inmutable: `(80, 443)`.
2. **Excepción `KeyError` por Acceso Directo (Tarea B):** La clave `"modo_depuracion"` no existe en el diccionario `configuracion`. Debe emplearse `.get("modo_depuracion", False)` para prevenir la interrupción del programa.
3. **Excepción `ValueError` en Bucle (Tarea C):** El método `.values()` solo devuelve una colección con los valores, no parejas. El bucle falla al intentar desempaquetar un único elemento en dos variables (`clave, valor`). Se debe utilizar `.items()`.
