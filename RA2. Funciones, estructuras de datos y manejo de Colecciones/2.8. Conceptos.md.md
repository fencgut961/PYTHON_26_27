## 📊 1. Métodos Avanzados y Ordenación en Listas

En el análisis de datos y la automatización de sistemas, es habitual requerir agregaciones numéricas o reordenaciones dinámicas de elementos.

### 📌 A. Modificación *In-Place* vs. Creación de Nuevas Colecciones

* 🆕 **`sorted(iterable)`**: Función global que devuelve una **nueva lista** ordenada, dejando la colección original intacta.
* 🛠️ **`lista.sort()`**: Método de objeto que ordena los elementos **in situ** (modifica directamente la lista en memoria y devuelve `None`).
* 🔄 **Parámetro `reverse=True**`: Invierte el criterio de ordenación para obtener secuencias descendentes.

```python
amenazas_score = [85, 12, 99, 45, 60]

# 1. Creación de una nueva lista ordenada (preserva la lista original)
ranking_ascendente = sorted(amenazas_score)

# 2. Ordenación in-place descendente (modifica la lista fuente)
amenazas_score.sort(reverse=True)

print("Original ordenada desc:", amenazas_score)  # [99, 85, 60, 45, 12]
print("Copia ordenada asc:", ranking_ascendente)    # [12, 45, 60, 85, 99]

```

### ⚙️ B. Ordenación Avanzada con `key` y Funciones `lambda`

Al trabajar con estructuras complejas (listas de tuplas o diccionarios), el parámetro `key` permite definir una función de extracción que determina el criterio exacto de ordenación.

```python
# Registros de incidentes: (ID, Nivel de Riesgo 0-100, Protocolo)
incidentes = [("INC-01", 85, "SSH"), ("INC-02", 99, "RDP"), ("INC-03", 40, "HTTP")]

# Ordenar los incidentes por el nivel de riesgo (índice 1 de cada tupla)
incidentes_por_riesgo = sorted(incidentes, key=lambda x: x[1], reverse=True)

print(incidentes_por_riesgo)
# Salida: [('INC-02', 99, 'RDP'), ('INC-01', 85, 'SSH'), ('INC-03', 40, 'HTTP')]

```

### 📈 C. Agregación y Métodos Extremos

* 📉 **`min(iterable)`** / 📈 **`max(iterable)`**: Devuelven el menor o mayor elemento de una colección. Aceptan opcionalmente el parámetro `key`.
* ➕ **`sum(iterable)`**: Devuelve la suma total de una colección puramente numérica.

```python
latencias_ms = [12.4, 8.1, 145.2, 22.0]

print(f"Latencia Mínima: {min(latencias_ms)} ms")
print(f"Latencia Máxima: {max(latencias_ms)} ms")
print(f"Latencia Promedio: {sum(latencias_ms) / len(latencias_ms):.2f} ms")

```

## 🗂️ 2. Métodos Avanzados de Diccionarios

El manejo profesional de diccionarios exige prevenir excepciones por claves ausentes y optimizar la combinación de registros.

### 🛡️ A. Asignación Defensiva con `.setdefault()`

El método `.setdefault(clave, valor_defecto)` realiza la siguiente lógica en una sola instrucción:

* 🟢 Si la clave **existe**, devuelve su valor actual sin modificar el diccionario.
* 🟡 Si la clave **no existe**, la inserta físicamente con el `valor_defecto` especificado y lo devuelve.

Es la herramienta estándar para agrupar o categorizar elementos dentro de listas dinámicas.

```python
# Categorización de puertos detectados por dirección IP
alertas_por_ip = {}

# Eventos entrantes: (IP, Puerto)
eventos = [("10.0.0.1", 22), ("192.168.1.5", 80), ("10.0.0.1", 443)]

for ip, puerto in eventos:
    # Garantiza que el valor sea una lista antes de invocar .append()
    alertas_por_ip.setdefault(ip, []).append(puerto)

print(alertas_por_ip)
# Salida: {'10.0.0.1': [22, 443], '192.168.1.5': [80]}

```

### 🔄 B. Fusionar y Actualizar con `.update()`

El método `.update(otro_diccionario)` combina dos estructuras en una sola operación. Inserta las claves nuevas y actualiza los valores de las claves que ya existían.

```python
config_base = {"firewall": True, "log_level": "INFO", "timeout": 30}
config_sobrescritura = {"log_level": "DEBUG", "retencion_dias": 90}

config_base.update(config_sobrescritura)

print(config_base)
# {'firewall': True, 'log_level': 'DEBUG', 'timeout': 30, 'retencion_dias': 90}

```

## ⚡ 3. Comprensión de Listas (*List Comprehensions*)

La **comprensión de listas** proporciona una sintaxis concisa para generar nuevas listas a partir de iterables, sustituyendo bucles `for` tradicionales por una expresión declarativa optimizada en C por el intérprete.

```text
               ┌─────────────────────── Expresión a evaluar o transformar
               │           ┌─────────── Bucle for sobre el iterable fuente
               │           │                     ┌────── Condición de filtrado (Opcional)
               ▼           ▼                     ▼
lista_nueva = [expresion for elemento in iterable if condicion]

```

### ⚖️ Comparativa: Bucle Tradicional vs. Comprensión

**Enfoque Tradicional:**

```python
puertos = [80, 22, 443, 3389, 21, 8080]
puertos_criticos = []

for p in puertos:
    if p < 1024:
        puertos_criticos.append(p)

```

**Enfoque Pythónico (Comprensión):**

```python
puertos = [80, 22, 443, 3389, 21, 8080]
puertos_criticos = [p for p in puertos if p < 1024]
# Resultado: [80, 22, 443, 21]

```

### 🔀 Comprensiones con Expresión Condicional (*If-Else*)

Si el objetivo no es filtrar elementos sino **transformarlos** en función de una condición, la estructura `if-else` se ubica **antes** de la cláusula `for`:

```python
puertos = [80, 8080, 22, 9000]

# Clasificación de puertos
etiquetas = ["ESTÁNDAR" if p < 1024 else "ALTO_RANGO" for p in puertos]

print(etiquetas)
# Salida: ['ESTÁNDAR', 'ALTO_RANGO', 'ESTÁNDAR', 'ALTO_RANGO']

```

## 🔍 4. Comprensión de Diccionarios (*Dict Comprehensions*)

Siguiendo la misma filosofía sintáctica, es posible construir mapas asociativos declarando un par `clave: valor`:

```text
dict_nuevo = {clave_exp: valor_exp for elemento in iterable if condicion}

```

### 🔁 A. Inversión y Filtrado de Diccionarios

```python
servicios_puertos = {"SSH": 22, "HTTP": 80, "HTTPS": 443, "RDP": 3389}

# 1. Invertir claves y valores
puertos_servicios = {puerto: servicio for servicio, puerto in servicios_puertos.items()}

# 2. Filtrar diccionarios (únicamente puertos web)
servicios_web = {k: v for k, v in servicios_puertos.items() if v in (80, 443)}

print(puertos_servicios) # {22: 'SSH', 80: 'HTTP', 443: 'HTTPS', 3389: 'RDP'}
print(servicios_web)     # {'HTTP': 80, 'HTTPS': 443}

```

### 🔗 B. Mapeo Múltiple con `zip()`

La función `zip()` combina dos o más iterables elemento a elemento, facilitando la creación de diccionarios a partir de listas independientes.

```python
servidores = ["SRV-WEB", "SRV-DB", "SRV-MAIL"]
ips = ["10.0.0.10", "10.0.0.20", "10.0.0.30"]

# Generación directa de mapa asociativo
mapa_red = {servidor: ip for servidor, ip in zip(servidores, ips)}

print(mapa_red)
# {'SRV-WEB': '10.0.0.10', 'SRV-DB': '10.0.0.20', 'SRV-MAIL': '10.0.0.30'}

```

## 💻 5. Ejemplo Integrador Completo

El siguiente script procesa y normaliza trazas de registros de red, combinando comprensiones de listas, ordenación por parámetros y agregación con diccionarios:

```python
"""
Módulo de auditoría de logs y filtrado masivo de amenazas.
Aplica List/Dict Comprehensions, sorted con lambda y .setdefault().
"""

LOGS_CRUDOS = [
    "2026-09-08 10:00:01|192.168.1.50|SSH|LOGIN_FAILED",
    "2026-09-08 10:00:03|10.0.0.88|HTTP|OK",
    "2026-09-08 10:00:05|192.168.1.50|SSH|LOGIN_FAILED",
    "2026-09-08 10:00:12|172.16.0.4|RDP|CRITICAL_ATTEMPT",
    "2026-09-08 10:00:15|192.168.1.50|SSH|LOGIN_FAILED"
]


def analizar_telemetria(logs: list) -> dict:
    """Parsea, filtra y contabiliza fallos de seguridad en logs de red.

    :param logs: Lista de cadenas de texto formateadas con delimitador '|'
    :return: Diccionario con IP sospechosas y recuento de fallos
    """
    # 1. Comprensión de listas: Descomponer registros en tuplas estructuradas
    registros_parsed = [tuple(log.split("|")) for log in logs]

    # 2. Filtrado con comprensión: Aislar eventos anómalos
    eventos_sospechosos = [
        (ip, proto, estado)
        for _, ip, proto, estado in registros_parsed
        if "FAILED" in estado or "CRITICAL" in estado
    ]

    # 3. Agregación dinámica utilizando .get()
    conteo_fallos = {}
    for ip, _, _ in eventos_sospechosos:
        conteo_fallos[ip] = conteo_fallos.get(ip, 0) + 1

    # 4. Ordenación avanzada: Ordenar IPs de mayor a menor número de fallos
    ips_ordenadas = sorted(
        conteo_fallos.items(), 
        key=lambda item: item[1], 
        reverse=True
    )

    return dict(ips_ordenadas)


# --- EJECUCIÓN PRINCIPAL ---
resultado_analisis = analizar_telemetria(LOGS_CRUDOS)

print("--- IPS CON ALERTAS CRÍTICAS DETECTADAS ---")
for ip_amenaza, total_eventos in resultado_analisis.items():
    print(f"IP: {ip_amenaza:<15} | Incidentes Detectados: {total_eventos}")

```

## 📝 6. Ejercicio de Diagnóstico

Analiza el siguiente fragmento de código e identifica los **3 errores lógicos o sintácticos**:

```python
# Tarea A: Intentar filtrar y transformar datos colocando el 'if-else' al final
puertos = [22, 80, 443, 3389]
estados = [p for p in puertos if p < 1024 "CRÍTICO" else "NORMAL"]

# Tarea B: Ordenar una lista de diccionarios sin especificar el parámetro 'key'
servidores = [{"host": "SRV-A", "cpu": 85}, {"host": "SRV-B", "cpu": 20}]
servidores.sort()

# Tarea C: Intentar usar comprensiones para modificar una lista in situ
amenazas = [10, 40, 90]
[a.append(0) for a in amenazas]

```

### 💡 Respuestas de Diagnóstico

1. ❌ **Error Sintáctico en Condicional Ternario (Tarea A):** Cuando se utiliza `if-else` para transformar elementos, toda la expresión condicional debe situarse **antes** del bucle `for`: `["CRÍTICO" if p < 1024 else "NORMAL" for p in puertos]`.
2. 🚨 **Excepción `TypeError` en Ordenación (Tarea B):** Python no puede comparar diccionarios completos directamente con `<`. Es obligatorio pasar el parámetro `key`: `servidores.sort(key=lambda s: s["cpu"])`.
3. ⚠️ **Uso Incorrecto de Comprensiones por Efectos Secundarios (Tarea C):** Las comprensiones de listas se diseñaron para **crear** nuevas colecciones retornando valores, no para ejecutar efectos secundarios en bucles (`.append()` retorna `None`, produciendo la lista `[None, None, None]`). Para modificar elementos *in-place* debe usarse un bucle `for` tradicional.
