## 1. Concepto y Propiedades de la Clase `list`

En el desarrollo de software, la gestión de datos requiere agrupar colecciones estructuradas de información. En Python, la **lista** es una secuencia lineal de elementos implementada como un vector dinámico de referencias a objetos.

```text
               Índices Positivos ──►     0           1           2
                                    ┌───────────┬───────────┬───────────┐
                  Lista de IPs:     │ "10.0.0.1"│ "10.0.0.2"│ "10.0.0.3"│
                                    └───────────┴───────────┴───────────┘
               Índices Negativos ──►    -3          -2          -1

```

### Características Fundamentales:

* **Ordenada:** Los elementos mantienen una secuencia física fija basada en su posición de inserción. Cada posición se identifica mediante un índice entero base cero (`0`).
* **Mutable:** Es posible alterar la lista (añadir, modificar o eliminar elementos) *in-situ* sin cambiar la dirección de memoria del objeto lista.
* **Heterogénea:** Una misma lista puede almacenar simultáneamente objetos de distintos tipos de datos (`int`, `float`, `str`, `bool` u otras listas).
* **Dinámica:** Ajusta su tamaño en memoria automáticamente según se inserten o eliminen registros.

```python
# Declaración de listas vacías e inicializadas
logs_evento = []  # Lista vacía (Sintaxis preferida)
servidores_activos = ["srv-auth", "srv-db", "srv-web"]  # Homogénea (str)
registro_auditoria = ["AUTH_FAIL", 401, True, 87.5]  # Heterogénea

```

## 2. Indexación y Modificación por Posición

El acceso a cualquier elemento de una lista se realiza en tiempo constante ($O(1)$) mediante el operador de indexación `[]`.

### A. Índices Positivos y Negativos

* **Índices Positivos (`0` a `N-1`):** Evalúan los elementos de izquierda a derecha.
* **Índices Negativos (`-1` a `-N`):** Evalúan los elementos de derecha a izquierda (siendo `-1` el último elemento de la colección).

```python
cluster = ["Nodo-Alpha", "Nodo-Beta", "Nodo-Gamma"]

print(cluster[0])   # Salida: 'Nodo-Alpha' (Primer elemento)
print(cluster[-1])  # Salida: 'Nodo-Gamma' (Último elemento)
print(cluster[-2])  # Salida: 'Nodo-Beta'  (Penúltimo elemento)

```

> ⚠️ **Excepción `IndexError`:** Intentar acceder o reasignar un índice fuera del rango existente (`0` a `len(lista) - 1`) provocará que Python lance un `IndexError: list index out of range`.

### B. Modificación Directa

Dado que las listas son mutables, podemos modificar cualquier elemento existente mediante reasignación directa sobre su índice:

```python
puertos_abiertos = [80, 443, 8080]
puertos_abiertos[2] = 8443  # Reemplaza 8080 por 8443

print(puertos_abiertos)  # Salida: [80, 443, 8443]

```

## 3. Operadores Nativos sobre Listas

Python permite utilizar varios operadores integrados para trabajar con secuencias de forma expresiva:

```python
# 1. Operador de Pertenencia (in / not in)
ips_bloqueadas = ["192.168.1.50", "10.0.0.99"]

if "192.168.1.50" in ips_bloqueadas:
    print("⛔ Acceso denegado: IP en lista negra.")

# 2. Operador de Concatenación (+) - Crea un NUEVO objeto lista
subred_a = ["10.0.1.1"]
subred_b = ["10.0.2.1"]
red_completa = subred_a + subred_b  # ['10.0.1.1', '10.0.2.1']

# 3. Operador de Repetición (*) - Duplica la secuencia
mascara_inicial = [0] * 4  # [0, 0, 0, 0]

```

## 4. Métodos Esenciales de la Clase `list`

La clase `list` incluye un conjunto de métodos para la manipulación de elementos. Es crucial diferenciar entre los métodos que **modifican la lista *in-place* (y devuelven `None`)** y los que **retornan un valor extraído**.

| Método | Firma / Propósito | Efecto en la Lista | Valor Retornado |
| --- | --- | --- | --- |
| **`append(x)`** | Añade el objeto `x` al **final** de la lista. | Modifica *in-place* | `None` |
| **`insert(i, x)`** | Inserta el objeto `x` en la **posición `i**`, desplazando el resto. | Modifica *in-place* | `None` |
| **`remove(x)`** | Elimina la **primera ocurrencia** del valor `x`. | Modifica *in-place* | `None` |
| **`pop(i)`** | Elimina y extrae el elemento en el índice `i` (por defecto `-1`). | Modifica *in-place* | El elemento extraído |
| **`sort()`** | Ordena la lista (por defecto ascendente). `reverse=True` para descendente. | Modifica *in-place* | `None` |
| **`index(x)`** | Busca el valor `x` y devuelve su posición de índice. | Sin cambios | `int` (Índice) |
| **`count(x)`** | Cuenta cuántas veces se repite el valor `x`. | Sin cambios | `int` (Frecuencia) |
| **`clear()`** | Elimina todos los elementos de la lista. | Modifica *in-place* | `None` |

```python
inventario = ["Poción", "Escudo"]

# Inserción
inventario.append("Espada")       # ["Poción", "Escudo", "Espada"]
inventario.insert(0, "Casco")     # ["Casco", "Poción", "Escudo", "Espada"]

# Extracción y Eliminación
objeto_usado = inventario.pop(1)  # Extrae "Poción"
inventario.remove("Escudo")       # Elimina "Escudo"

print(f"Objeto usado: {objeto_usado}") # Poción
print(f"Inventario final: {inventario}") # ['Casco', 'Espada']

```

> ⚠️ **Incompatibilidad en `remove()`:** Si se intenta ejecutar `.remove(valor)` sobre un elemento que **no existe** en la lista, Python lanzará una excepción `ValueError: list.remove(x): x not in list`. Es buena práctica validar la existencia previa con `in`.

## 🛑 5. Gestión de Memoria: Referencias vs. Copias Superficiales (*Shallow Copy*)

Un error crítico en Python es asumir que asignar una lista a una nueva variable mediante el operador de igualdad (`=`) crea un nuevo objeto independiente.

### A. Asignación de Referencia (Aliasing)

Cuando escribes `lista_b = lista_a`, **no estás duplicando los datos**. Ambas variables apuntan exactamente a la misma dirección en la memoria *heap*. Cualquier modificación realizada mediante una variable afectará inmediatamente a la otra.

```python
# ❌ ERROR DE ALIASING (Misma dirección de memoria)
original = [10, 20, 30]
alias = original  # Ambas variables apuntan al mismo objeto

alias.append(999)

print(original)  # Salida: [10, 20, 30, 999] (¡El original se alteró!)
print(original is alias)  # True (Son el mismo objeto)

```

### B. Copia Física Independiente (`.copy()`)

Para duplicar los datos de forma segura en un nuevo bloque de memoria de manera que las modificaciones posteriores se mantengan aisladas, debes invocar el método `.copy()` (o el operador de troceado `[:]`).

```python
# ✅ COPIA FÍSICA AUTÓNOMA
original = [10, 20, 30]
copia_segura = original.copy()  # Crea una nueva lista en memoria

copia_segura.append(999)

print(original)      # Salida: [10, 20, 30] (Intacto)
print(copia_segura)  # Salida: [10, 20, 30, 999]
print(original is copia_segura)  # False (Objetos distintos)

```

## 💻 6. Ejemplo Integrador Completo

El siguiente script administra la cola de peticiones de un servidor de juegos mediante listas y métodos de mutación seguros:

```python
"""
Módulo de gestión de cola de jugadores para servidores de SteamArcade.
Demuestra el uso de métodos mutadores de la clase list y prevención de aliasing.
"""

# --- BASE DE DATOS LOCAL DE JUGADORES ---
cola_espera = ["Jugador_Alpha", "Jugador_Beta", "Jugador_Gamma"]


def procesar_siguiente_jugador(cola):
    """Extrae y atiende al primer jugador en la cola de entrada.

    :param cola: Objeto lista con los nombres de usuarios conectados.
    :return: Nombre del jugador procesado (str) o None si la cola está vacía.
    """
    if not cola:  # Evalúa si la lista está vacía
        return None
    return cola.pop(0)  # Extrae el primer elemento desplazando el resto


def agregar_jugador_prioritario(cola, nombre_usuario):
    """Inserta un usuario VIP al inicio de la cola de juego.

    :param cola: Objeto lista objetivo.
    :param nombre_usuario: Cadena con el identificador del jugador.
    """
    cola.insert(0, nombre_usuario)


# --- EJECUCIÓN PRINCIPAL ---
print(f"Cola inicial: {cola_espera}")

# 1. Creación de respaldo seguro para auditoría (Copia física)
respaldo_auditoria = cola_espera.copy()

# 2. Agregar VIP al inicio
agregar_jugador_prioritario(cola_espera, "VIP_King")
print(f"Cola tras ingreso VIP: {cola_espera}")

# 3. Procesar turno del primer jugador
atendido = procesar_siguiente_jugador(cola_espera)
print(f"🎮 Entrando a la partida: {atendido}")

# 4. Verificación de independencia de memoria
print(f"Cola activa actual: {cola_espera}")
print(f"Respaldo de auditoría intacto: {respaldo_auditoria}")

```

## 📝 Ejercicio de Diagnóstico

Analiza el siguiente fragmento de código e identifica los **3 errores lógicos o de ejecución** relacionados con el uso de listas:

```python
precios_euros = [15.0, 49.99, 5.50]

# Tarea A: Ordenar la lista de forma descendente y guardarla
precios_ordenados = precios_euros.sort(reverse=True)

# Tarea B: Intentar eliminar un producto que ya no está en catálogo
precios_euros.remove(100.0)

# Tarea C: Imprimir el precio más alto de la lista ordenada
print(f"El mayor precio es: {precios_ordenados[0]}")

```

### Respuestas de Diagnóstico:

1. **Error de Retorno `None` en `sort()`:** El método `.sort()` modifica la lista *in-place* y devuelve `None`. Por lo tanto, `precios_ordenados` almacenará el valor `None` en lugar de una lista.
2. **Excepción `ValueError` en `remove()`:** La instrucción `precios_euros.remove(100.0)` fallará con un `ValueError` porque el número `100.0` no está presente dentro de la lista. Se debe comprobar previamente con `if 100.0 in precios_euros:`.
3. **Excepción `TypeError` en Indexación:** Al intentar ejecutar `precios_ordenados[0]`, Python lanzará un `TypeError: 'NoneType' object is not subscriptable`, ya que `precios_ordenados` es `None` debido al error cometido en la Tarea A.
