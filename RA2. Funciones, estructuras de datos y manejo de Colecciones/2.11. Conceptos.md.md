## 1. ¿Qué es un Iterable?

Un **iterable** es cualquier objeto capaz de devolver sus elementos uno a uno. Es el contenedor original de la información, pero no guarda el estado de la lectura ni recuerda en qué posición se encuentra el recorrido.

### Ejemplos comunes de iterables:

* **Colecciones mutables e inmutables:** `list`, `tuple`, `set`, `dict`.
* **Cadenas de texto:** `str` (se recorren carácter a carácter).
* **Generadores de secuencias:** `range()`.

Cualquier iterable se puede recorrer directamente mediante un bucle `for`:

```python
servidores = ["SRV-Web", "SRV-DB", "SRV-Mail"]

for s in servidores:
    print(s)

```

---

## 2. ¿Qué es un Iterador?

Un **iterador** es el objeto físico encargado de **realizar el recorrido** sobre un iterable. Mantiene en memoria el estado actual de la iteración, recordando qué elemento ha procesado y cuál es el siguiente.

### Cómo trabajar con iteradores de forma manual:

1. **Crear el iterador:** Se pasa el iterable a la función integrada `iter()`.
2. **Avanzar de elemento:** Se solicita el siguiente valor con la función integrada `next()`.
3. **Fin de la iteración:** Cuando no quedan más elementos, `next()` lanza automáticamente la excepción **`StopIteration`**.

```python
ips_atacantes = ["10.0.0.1", "192.168.1.50"]

# 1. Creamos el iterador
lector = iter(ips_atacantes)

# 2. Solicitamos elementos secuencialmente
print(next(lector))  # Salida: 10.0.0.1
print(next(lector))  # Salida: 192.168.1.50

# 3. Al quedarse sin elementos, lanza error de parada
print(next(lector))  # ❌ Lanza excepción: StopIteration

```

---

## 3. Comparativa: Iterable vs. Iterador

| Propiedad | Iterable | Iterador |
| --- | --- | --- |
| **¿Contiene los datos?** | Sí, es el contenedor original de la información. | No necesariamente; solo conoce el flujo y la posición actual. |
| **¿Mantiene el estado?** | No. Si se interrumpe, no recuerda por dónde iba. | Sí. Recuerda siempre cuál es el siguiente elemento. |
| **¿Soporta `next()`?** | No. Intentar hacer `next(lista)` lanza un `TypeError`. | Sí. Es su operación fundamental para avanzar en memoria. |
| **Métodos internos** | Implementa el método especial `__iter__()`. | Implementa los métodos especiales `__iter__()` y `__next__()`. |

## 4. Avance Seguro: `next()` con Valor por Defecto

En scripts de producción o automatización en tiempo real, permitir que un programa se detenga con una excepción no controlada (`StopIteration`) interrumpe el flujo de ejecución.

Para evitar esto, la función `next()` acepta un **segundo argumento opcional** que actúa como valor por defecto o centinela. Si el iterador se agota, en lugar de lanzar una excepción, devolverá dicho valor (habitualmente `None`):

```python
nombres = ["admin", "analista"]
it = iter(nombres)

# Consumo manual seguro
while True:
    usuario = next(it, None)
    if usuario is None:
        print("Fin de la lista de usuarios. Deteniendo auditoría.")
        break
    print(f"Auditando acceso de: {usuario}")

```

Esta técnica permite simular el comportamiento de un bucle `for` manteniendo control absoluto sobre el momento exacto en el que se solicita el siguiente dato.

## 5. Iteradores con Función Centinela (Generadores Infinitos)

Python permite utilizar `iter()` pasando dos argumentos: una **función** (*callable*) y un **valor centinela** de parada. El iterador llamará a la función de manera continua hasta que el valor devuelto coincida con el centinela.

```python
import random

def generar_puerto():
    # Simula la lectura de puertos abiertos en un firewall
    return random.randint(20, 25)

# El iterador invocará generar_puerto() hasta que devuelva el puerto 22 (SSH)
it_puertos = iter(generar_puerto, 22)

for puerto in it_puertos:
    print(f"Escaneando puerto seguro: {puerto}")

print("🚨 ¡Alerta! Detectado puerto 22 (SSH) abierto. Deteniendo escaneo.")

```

## 💻 6. Ejemplo Integrador Completo

El siguiente script procesa una cola de eventos de seguridad capturados por un sensor de red, consumiendo el flujo de manera manual mediante iteradores y controlando situaciones de agotamiento de datos con un valor por defecto:

```python
"""
Módulo de procesamiento de telemetría de red basado en iteradores.
Demuestra la creación manual de iteradores, avance con next() y valores centinela.
"""

# Flujo de datos crudo recibido del sensor de red
COLA_EVENTOS = [
    {"id": 101, "evento": "CONEXION_ESTABLECIDA", "riesgo": "BAJO"},
    {"id": 102, "evento": "INTENTO_ACCESO_DENEGADO", "riesgo": "MEDIO"},
    {"id": 103, "evento": "INJECCION_SQL_DETECTADA", "riesgo": "ALTO"}
]


def procesar_flujo_eventos(eventos: list) -> int:
    """Consume secuencialmente un flujo de eventos de seguridad mediante un iterador.

    :param eventos: Lista de diccionarios con la telemetría de red
    :return: Cantidad total de eventos procesados con éxito
    """
    # Creación del iterador sobre el iterable original
    iterador_eventos = iter(eventos)
    procesados = 0

    print("--- INICIANDO PROCESAMIENTO MANUAL DE EVENTOS ---")

    while True:
        # Avance seguro mediante valor por defecto
        evento = next(iterador_eventos, None)

        if evento is None:
            print("\n[INFO] Se ha alcanzado el final del flujo de datos.")
            break

        procesados += 1
        print(f"Procesando Evento #{evento['id']}: [{evento['riesgo']}] - {evento['evento']}")

    return procesados


# --- EJECUCIÓN PRINCIPAL ---
if __name__ == "__main__":
    total = procesar_flujo_eventos(COLA_EVENTOS)
    print(f"Total de registros procesados por el auditor: {total}")

```

## 📝 7. Ejercicio de Diagnóstico

Analiza el siguiente fragmento de código e identifica los **3 errores lógicos o sintácticos**:

```python
# Tarea A: Intentar llamar a next() directamente sobre un iterable
ips = ["192.168.1.1", "10.0.0.1"]
primera_ip = next(ips)

# Tarea B: Bucle infinito por mal uso de next() con valor por defecto
puertos = [80, 443]
it_puertos = iter(puertos)

while next(it_puertos, None):
    print("Puerto procesado correctamente")

# Tarea C: Intentar usar un valor no ejecutable (non-callable) en iter() con centinela
cadena_estatica = "TRAFICO_NORMAL"
it_centinela = iter(cadena_estatica, "NORMAL")

```

### 💡 Respuestas de Diagnóstico

1. 🚨 **Error de Tipo al Invocar `next()` sobre un Iterable (Tarea A):** La variable `ips` es una lista (iterable), no un iterador. Invocarla directamente con `next(ips)` lanzará `TypeError: 'list' object is not an iterator`. Se debe convertir previamente con `iter(ips)`.
2. ⚠️ **Bucle Infinito y Consumo Doble (Tarea B):** En la condición del `while`, se evalúa `next(it_puertos, None)`. Esto consume el primer elemento (`80`). Luego, dentro del bloque del bucle, no se vuelve a avanzar ni a reasignar el estado, pero la condición `while` volverá a evaluar y consumir `443` y, cuando devuelva `None`, romperá. No obstante, si la lista tuviera valores falsables como `0` o `False`, la evaluación lógica fallaría prematuramente. El patrón correcto exige asignar el resultado a una variable: `while (p := next(it_puertos, None)) is not None:`.
3. ❌ **Excepción `TypeError` por Argumento no Invocable (Tarea C):** La sintaxis `iter(callable, sentinel)` requiere que el primer parámetro sea una **función o elemento ejecutable** (como un método o una función lambda). Pasar la cadena `cadena_estatica` lanzará `TypeError: 'str' object is not callable`.
