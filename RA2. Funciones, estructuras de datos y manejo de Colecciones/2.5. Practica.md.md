# 🔹 Práctica 2.5 - Firewall IP Threat Intelligence & Blacklist Manager

---

## 📖 Contexto del Proyecto

En el área de ciberseguridad, los **Firewalls** y los **Sistemas de Prevención de Intrusos (IPS)** gestionan dinámicamente listas de direcciones IP sospechosas o maliciosas para bloquear conexiones no autorizadas.

En esta actividad práctica, construirás una herramienta de consola para administrar la inteligencia de amenazas de un firewall corporativo. Manipularás una **lista mutable** de direcciones IP en Python (`blacklist`), añadiendo amenazas activas, revocando falsos positivos, simulando la inspección de paquetes de red y emitiendo reportes ordenados.

---

## 🎯 El Reto

Escribirás un script ejecutable en Python denominado **`ra2_act5_firewall_manager.py`** que simule el centro de administración de un firewall de red.

El programa gestionará el estado de la lista de bloqueo mediante funciones puras y parametrizadas, garantizando la integridad de los datos en memoria mediante el uso correcto de **copias independientes (`.copy()`)** y metodos mutadores de la clase `list`.

---

## 🚫 Restricciones Técnicas (Patrón Anti-IA)

👉 Para garantizar la evaluación objetiva sobre el uso de la clase `list`:

* **Nombre obligatorio del archivo:** `ra2_act5_firewall_manager.py`.
* **Uso estricto de `.copy()`:** La función `exportar_reporte()` **debe** crear una copia física independiente antes de aplicar `.sort()` para evitar modificar el orden original de la lista principal en memoria.
* **Saneamiento obligatorio:** Todas las entradas de usuario leídas mediante `input()` deben sanearse utilizando `.strip()` para prevenir imprecisiones por espacios accidentales.
* **Manejo seguro de eliminación:** En `eliminar_falso_positivo()`, **debe comprobarse previamente** la existencia del elemento mediante el operador `in` antes de invocar `.remove()` para evitar excepciones no controladas (`ValueError`).
* **Estándar PEP 8 y PEP 257:** El código debe incluir **Docstrings multilínea** en comillas triples `"""` para cada función y seguir las convenciones de nombres en `snake_case`.

## 🛠️ Requisitos de Implementación

### 1. Funciones Requeridas

#### `inicializar_blacklist()`

* **Firma:** `inicializar_blacklist() -> list`
* **Propósito:** Crea y retorna la lista inicial de trabajo con 5 IPs bloqueadas de referencia.
* **Valores obligatorios:** `["192.168.1.50", "10.0.0.99", "8.8.4.4", "172.16.25.10", "195.235.12.3"]`.

#### `registrar_amenaza(blacklist, ip)`

* **Firma:** `registrar_amenaza(blacklist: list, ip: str) -> None`
* **Lógica:**
1. Aplica `.strip()` a la dirección `ip`.
2. Evalúa si la IP ya existe en `blacklist` con el operador `in`.
3. Si ya existe, muestra: `[!] Advertencia: La IP {ip} ya está en la blacklist.`
4. Si no existe, la añade al final de la lista con `.append()` y muestra: `[+] IP {ip} bloqueada con éxito.`



#### `eliminar_falso_positivo(blacklist, ip)`

* **Firma:** `eliminar_falso_positivo(blacklist: list, ip: str) -> None`
* **Lógica:**
1. Aplica `.strip()` a la dirección `ip`.
2. Verifica si la IP se encuentra en la lista.
3. Si está presente, la elimina con `.remove()` y muestra: `[-] IP {ip} retirada de la blacklist.`
4. Si no está, notifica: `[?] Error: La IP {ip} no se encuentra registrada.`



#### `comprobar_trafico(blacklist, ip_origen)`

* **Firma:** `comprobar_trafico(blacklist: list, ip_origen: str) -> None`
* **Lógica:**
1. Aplica `.strip()` a la IP recibida.
2. Si la IP pertenece a la `blacklist`, muestra: `[ACCESO DENEGADO ⛔] Conexión bloqueada desde {ip_origen}.`
3. De lo contrario, muestra: `[ACCESO CONCEDIDO ✅] Paquete aceptado desde {ip_origen}.`



#### `exportar_reporte(blacklist)`

* **Firma:** `exportar_reporte(blacklist: list) -> None`
* **Lógica:**
1. Genera una **copia independiente** de la lista recibida mediante `.copy()`.
2. Ordena alfabéticamente la copia usando `.sort()`.
3. Imprime el listado ordenado mostrando un índice incremental (ejemplo: `[1] - 8.8.4.4`) y el total de amenazas activas al final.

## 🎛️ Flujo del Programa Principal (Menú Interactivo)

El punto de entrada ejecutable cargará la lista inicial invocando a `inicializar_blacklist()` y desplegará una estructura iterativa `while True` con las siguientes opciones:

```text
=== FIREWALL THREAT INTELLIGENCE ===
1. Ver Blacklist ordenada (Reporte)
2. Registrar nueva amenaza (IP)
3. Retirar falso positivo (Desbloquear)
4. Simular tráfico entrante (Auditoría)
5. Salir

```

* **Opción 1:** Invoca a `exportar_reporte(blacklist_actual)`.
* **Opción 2:** Solicita una IP por teclado, lee la entrada y llama a `registrar_amenaza()`.
* **Opción 3:** Solicita una IP a desbloquear por teclado y llama a `eliminar_falso_positivo()`.
* **Opción 4:** Solicita la IP de origen de un paquete entrante y llama a `comprobar_trafico()`.
* **Opción 5:** Finaliza la ejecución imprimiendo un mensaje de cierre y ejecutando `break`.
