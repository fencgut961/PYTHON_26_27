# 🔹 Práctica 2.7 - SOC Incident Ticket Manager (CRUD)

---

## 📖 Contexto del Proyecto

En los centros de operaciones de ciberseguridad (SOC), la rapidez para categorizar, registrar, actualizar y mitigar incidentes es crucial para la supervivencia de la infraestructura corporativa.

En esta actividad práctica, asumirás el rol de desarrollador de herramientas internas para un equipo de Respuesta a Incidentes (*Incident Response*). Tu misión es programar una base de datos local en memoria que funcione como un sistema interactivo de **Gestión de Tickets de Incidentes de Ciberseguridad (CRUD)** utilizando diccionarios estructurados y control de flujo mediante la instrucción `match-case`.

---

## 🎯 El Reto

Desarrollarás un script interactivo en Python denominado **`ra2_act7_gestor_incidentes.py`** que simule el motor de gestión de un SOC.

El programa administrará un diccionario anidado principal y permitirá realizar las cuatro operaciones fundamentales sobre la base de datos de incidentes: **Crear** (*Create*), **Leer** (*Read*), **Actualizar** (*Update*) y **Eliminar** (*Delete*), garantizando la estabilidad del sistema mediante programación defensiva.

---

## 🚫 Restricciones Técnicas (Patrón Anti-IA)

👉 Para garantizar la evaluación objetiva sobre el uso de diccionarios y operaciones CRUD:

* **Nombre obligatorio del archivo:** `ra2_act7_gestor_incidentes.py` (o `b2_7_gestor_incidentes.py`).
* **Estructura anidada obligatoria:** La base de datos debe ser un diccionario donde las claves sean identificadores únicos (`"INC-001"`) y los valores sean diccionarios con la información del incidente.
* **Acceso seguro y verificación previa:** Se debe emplear el método `.get()` o el operador de pertenencia `in` para verificar la existencia de un ticket antes de actualizarlo o eliminarlo, evitando excepciones `KeyError`.
* **Saneamiento de datos:** Toda entrada por teclado debe limpiarse con `.strip()` y normalizarse sintácticamente (por ejemplo, con `.capitalize()`).
* **Estructura de control moderna:** El menú principal debe implementarse utilizando la sentencia `match-case`.
* **Estándar PEP 8 y PEP 257:** El código debe incluir **Docstrings multilínea** (`"""`) en cada función y nombres en `snake_case`.

El programa trabajará sobre una estructura de diccionario anidado inicializada con el siguiente formato:

```python
tickets_soc = {
```

## 🛠️ Requisitos de Implementación (Funciones CRUD)

### 1. `registrar_incidente(tickets, id_ticket, host, severidad, analista)` — *Create*

* **Firma:** `registrar_incidente(tickets: dict, id_ticket: str, host: str, severidad: str, analista: str) -> None`
* **Lógica:**
1. Verifica si `id_ticket` ya existe en `tickets`.
2. Si existe, muestra: `[!] Error: El ticket {id_ticket} ya está registrado.` y cancela la operación.
3. Si no existe, sanea los textos con `.strip()` y agrega la entrada con el estado por defecto `"Abierto"`. Muestra un mensaje de confirmación.



### 2. `mostrar_incidentes(tickets)` — *Read*

* **Firma:** `mostrar_incidentes(tickets: dict) -> None`
* **Lógica:**
1. Si `tickets` está vacío, notifica: `⚠️ No hay incidentes registrados en el SOC.`
2. Si contiene elementos, recorre la estructura utilizando `.items()` y despliega un panel formateado mostrando la clave y cada uno de los campos anidados.



### 3. `actualizar_estado(tickets, id_ticket, nuevo_estado)` — *Update*

* **Firma:** `actualizar_estado(tickets: dict, id_ticket: str, nuevo_estado: str) -> None`
* **Lógica:**
1. Consulta de forma segura si `id_ticket` existe en `tickets`.
2. Si existe, actualiza la clave `"estado"` asignando `nuevo_estado.strip().capitalize()`.
3. Si no existe, informa el error de manera amigable sin interrumpir la ejecución.



### 4. `eliminar_incidente(tickets, id_ticket)` — *Delete*

* **Firma:** `eliminar_incidente(tickets: dict, id_ticket: str) -> None`
* **Lógica:**
1. Verifica la existencia de `id_ticket`.
2. Si existe, utiliza `.pop(id_ticket)` para extraer y eliminar el registro, notificando el host y analista desvinculados.
3. Si no existe, muestra un aviso indicando que el ticket no se ha encontrado.
