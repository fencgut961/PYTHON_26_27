## 1. Concepto y Propiedades de la Clase `tuple`

Una **tupla** es una secuencia lineal de elementos **ordenada e inmutable**. Una vez instanciada en memoria, su tamaño y sus componentes no pueden ser alterados, añadidos ni eliminados.

```text
               Índices Positivos ──►     0              1            2
                                    ┌──────────────┬───────────┬─────────┐
             Registro Específico:   │ "2026-09-08" │ "10.0.0.1"│  8080   │
                                    └──────────────┴───────────┴─────────┘
               Índices Negativos ──►    -3             -2           -1

```

### Características Fundamentales:

* **Inmutable:** No admite métodos de mutación (*in-place*) como `append()`, `remove()` o asignación directa por índice.
* **Ordenada:** Mantiene una secuencia física basada en índices enteros con base cero (`0`).
* **Heterogénea:** Permite almacenar simultáneamente distintos tipos de datos (`str`, `int`, `float`, `bool`, u otros objetos).
* **Eficiente:** Ocupa menos espacio en memoria y ofrece lecturas ligeramente más rápidas que las listas.

```python
# Instanciación de tuplas
evidencia_vacia = ()  # Tupla vacía
ioc_registro = ("192.168.1.105", "Malware_Trojan", 8080, True)

```

---

## 2. Comparativa: Listas (`list`) vs. Tuplas (`tuple`)

| Criterio | Lista (`list`) | Tupla (`tuple`) |
| --- | --- | --- |
| **Sintaxis** | Corchetes `[ ]` | Paréntesis `( )` |
| **Mutabilidad** | **Mutable** (se altera *in-place*) | **Inmutable** (estado constante) |
| **Desempeño** | Mayor consumo de memoria | Más ligera y optimizada en CPU |
| **Casos de Uso** | Colecciones dinámicas y cambiantes | Registros históricos, coordenadas, configuraciones |
| **Uso como clave en dict** | ❌ No permitido (`unhashable`) | ✅ Permitido (`hashable`) |

## 3. Indexación, Slicing e Inmutabilidad

El acceso a los elementos de una tupla se realiza mediante el operador de indexación `[]`, funcionando exactamente igual que en las listas.

```python
incidente = ("2026-09-08", "10.0.0.1", "Intrusión SSH", 22)

# Acceso directo
print(incidente[0])   # Salida: '2026-09-08' (Primer elemento)
print(incidente[-1])  # Salida: 22 (Último elemento)

# Subsección (Slicing) -> Retorna una NUEVA tupla
detalles = incidente[1:3]  # ('10.0.0.1', 'Intrusión SSH')

```

### Violación de Inmutabilidad

Intentar reasignar un valor dentro de una tupla mediante su índice generará un error de ejecución inmediato:

```python
incidente = ("2026-09-08", "10.0.0.1", "Intrusión SSH", 22)

# ❌ INTENTO INCORRECTO:
# incidente[1] = "192.168.1.50"
# TypeError: 'tuple' object does not support item assignment

```

## 4. Particularidad Sintáctica: Tupla Unitaria

Para declarar una tupla que contenga **un único elemento**, es obligatorio colocar una **coma final (`,`)** antes de cerrar el paréntesis. De lo contrario, el intérprete tratará los paréntesis como un operador sintáctico de agrupación (evaluando el contenido como un tipo simple).

```python
# ❌ Error sintáctico común (se evalúa como 'str')
falso_registro = ("192.168.1.1")
print(type(falso_registro))  # <class 'str'>

# ✅ Tupla unitaria correcta (requiere la coma)
registro_seguro = ("192.168.1.1",)
print(type(registro_seguro))  # <class 'tuple'>

```

## 5. Desempaquetado de Tuplas (*Unpacking*)

El desempaquetado permite extraer el contenido de una tupla y asignarlo a múltiples variables independientes en una única línea de código.

```python
ioc = ("Ransomware_WannaCry", 443, "Crítico")

# Desempaquetado posicional
nombre_threat, puerto, nivel_riesgo = ioc

print(nombre_threat)  # Ransomware_WannaCry
print(puerto)         # 443

```

> ⚠️ **Excepción `ValueError`:** El número de variables receptoras debe coincidir exactamente con el total de elementos de la tupla. Si hay discrepancia, Python lanzará `ValueError: too many values to unpack` o `not enough values to unpack`.

---

## 6. Conversión entre Listas y Tuplas

Cuando se requiere modificar datos almacenados en una tupla, se realiza una conversión temporal a lista (`list()`), se aplica la mutación necesaria y se re-convierte a tupla (`tuple()`) para proteger la integridad del resultado.

```python
# 1. Tupla inmutable original
ioc_original = ("10.0.0.2", "Malicioso", 80)

# 2. Conversión a lista para edición
ioc_editable = list(ioc_original)
ioc_editable[1] = "Falso Positivo"  # Modificación permitida en listas
ioc_editable.append("Revisado")

# 3. Conversión final a tupla inmutable
ioc_definitivo = tuple(ioc_editable)

print(ioc_definitivo)
# Salida: ('10.0.0.2', 'Falso Positivo', 80, 'Revisado')

```

---

## 7. Métodos Integrados del Objeto `tuple`

Al no ser editable, la clase `tuple` solo cuenta con dos métodos de inspección:

* **`count(x)`**: Devuelve el número de veces que el valor `x` aparece en la tupla.
* **`index(x)`**: Devuelve el índice de la primera ocurrencia del valor `x`. Lanza `ValueError` si el elemento no existe.

```python
puertos_escaneados = (80, 443, 80, 22, 80, 8080)

print(puertos_escaneados.count(80))   # Salida: 3
print(puertos_escaneados.index(443))  # Salida: 1

```

## 8. Uso Avanzado: Tuplas como Claves de Diccionarios (*Hashability*)

Las claves de un diccionario en Python deben ser objetos **hashables** (cuyo valor de hash no varíe durante su ciclo de vida). Las listas son mutables y no-hashables, pero las tuplas sí pueden usarse como claves compuestas.

```python
# Mapeo de pares (IP Origen, IP Destino) a estado de inspección
registro_firewall = {
    ("192.168.1.10", "10.0.0.1"): "Permitido",
    ("172.16.0.5", "185.220.101.3"): "Bloqueado"
}

# Consulta directa usando la tupla como clave
par_red = ("172.16.0.5", "185.220.101.3")
estado = registro_firewall[par_red]

print(f"Estado de conexión {par_red}: {estado}")
# Salida: Estado de conexión ('172.16.0.5', '185.220.101.3'): Bloqueado

```

## 💻 9. Ejemplo Integrador Completo

El siguiente script procesa evidencias forenses, descompone indicadores mediante *unpacking* y audita accesos empleando tuplas como claves:

```python
"""
Módulo forense para procesamiento e inspección inmutable de evidencias de red.
Demuestra desempaquetado, conversión de tipos y hashability de tuplas.
"""

# --- REGISTROS HISTÓRICOS INMUTABLES ---
EVIDENCIA_RAW = ("2026-09-08", "192.168.1.100", 443, "Tráfico Inusual")


def Auditar_evidencia(evidencia: tuple) -> dict:
    """Procesa una evidencia forense inmutable y calcula su diccionario de estado.

    :param evidencia: Tupla con la estructura (fecha, ip, puerto, evento)
    :return: Diccionario indexado por el par (ip, puerto)
    """
    # 1. Desempaquetado seguro de los elementos
    fecha, ip_origen, puerto, evento = evidencia

    # 2. Conversión temporal a lista para actualizar la etiqueta de evento
    lista_detalles = list(evidencia)
    lista_detalles[3] = f"ANALIZADO: {evento}"

    # 3. Creación de tupla inmutable de reporte
    evidencia_procesada = tuple(lista_detalles)

    # 4. Uso de tupla compuestas como clave del diccionario
    clave_mapa = (ip_origen, puerto)
    base_datos_forense = {clave_mapa: evidencia_procesada}

    return base_datos_forense


# --- EJECUCIÓN PRINCIPAL ---
resultado = Auditar_evidencia(EVIDENCIA_RAW)
clave_busqueda = ("192.168.1.100", 443)

print("--- REPORTE DE AUDITORÍA FORENSE ---")
print(f"Clave de consulta: {clave_busqueda}")
print(f"Registro asociado: {resultado[clave_busqueda]}")

```

## 📝 Ejercicio de Diagnóstico

Analiza el siguiente fragmento de código e identifica los **3 errores lógicos o de ejecución** relacionados con el uso de tuplas:

```python
# Tarea A: Crear una tupla unitaria con el servidor principal
servidor_base = ("10.0.0.1")

# Tarea B: Intentar modificar el puerto asignado en la tupla
configuracion = ("SSH", 22, "Activo")
configuracion[1] = 2222

# Tarea C: Desempaquetar los datos de configuración
servicio, puerto = configuracion

```

### Respuestas de Diagnóstico:

1. **Error en Tupla Unitaria (Tarea A):** La variable `servidor_base` no es una tupla, sino una cadena de texto (`str`), debido a la falta de la coma final. Debe escribirse como `("10.0.0.1",)`.
2. **Excepción `TypeError` por Mutación (Tarea B):** La línea `configuracion[1] = 2222` genera un `TypeError: 'tuple' object does not support item assignment` porque las tuplas son inmutables.
3. **Excepción `ValueError` en Desempaquetado (Tarea C):** La instrucción `servicio, puerto = configuracion` falla con `ValueError: too many values to unpack (expected 2)` porque `configuracion` contiene 3 elementos y solo se proporcionaron 2 variables receptoras.
